# Design Philosophy

- "no guilt": Skip은 스트릭 안 깨짐, 성장 마인드셋 메시지 사용
- 최소 마찰: 원탭 체크인 (Done/Skip)
- 맥락 제공: Task 카드에 Phase → Goal → Area 경로 표시
- Progressive disclosure: 기본은 심플, 상세는 필요 시만
- 색상: Done=Green, Skip=Gray, Miss=Soft Red, Streak=Orange, AI=Blue/Purple
- 자세한 가이드: @docs/plan/core/design-guide.md
