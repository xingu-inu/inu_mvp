# 수익 모델

> Free + Pro 2티어 구조

---

## 티어 구조

| 티어     | 가격                     | 대상                                  |
| -------- | ------------------------ | ------------------------------------- |
| **Free** | 영구 무료                | 핵심 루프를 경험하고 싶은 모든 사용자 |
| **Pro**  | 월 3,900원 / 연 29,000원 | AI 풀버전 + 상세 분석이 필요한 사용자 |

---

## Free 티어

### 포함 기능

| 카테고리       | 기능                                |
| -------------- | ----------------------------------- |
| **로드맵**     | Area/Goal/Phase/Task 무제한         |
| **체크인**     | 원탭 체크인, 스트릭, 기분 선택      |
| **Why 시스템** | 모든 레벨 Why 입력/표시             |
| **캘린더**     | 시간대별 그룹핑, 주간/월간 뷰       |
| **리뷰**       | 주간 달성률 (간소화), 저널 타임라인 |
| **검색**       | 통합 검색                           |
| **AI**         | 넛지 카드 **1일 3회**               |

### 제한

| 제한      | 내용                            |
| --------- | ------------------------------- |
| AI 횟수   | 1일 3회 (넛지 + 액션 카드 합산) |
| 월간 리뷰 | 기본만 (추이 그래프 없음)       |
| 인사이트  | 기본 통계만                     |

---

## Pro 티어

### 추가 기능

| 카테고리     | 기능                                        |
| ------------ | ------------------------------------------- |
| **AI**       | 무제한 (넛지, 액션 카드, 자세히 이야기하기) |
| **리뷰**     | 월간 리뷰 풀버전 (추이 그래프, 레이더 차트) |
| **인사이트** | 1% 성장 리포트, 히트맵                      |
| **분석**     | 시간 패턴 분석, 최적 시간대 추천            |
| **WOOP**     | 장애물 감지 카드                            |
| **캘린더**   | Google Calendar 연동 (Phase 2)              |

### 가격

| 플랜 | 가격        | 월 환산            |
| ---- | ----------- | ------------------ |
| 월간 | 3,900원/월  | 3,900원            |
| 연간 | 29,000원/년 | 2,417원 (38% 할인) |

---

## 전환 전략

### Free → Pro 전환 트리거

| 트리거         | 메시지                                                              |
| -------------- | ------------------------------------------------------------------- |
| AI 3회 소진    | "오늘 AI 사용량을 모두 사용했어요. Pro로 업그레이드하면 무제한!"    |
| 30일 연속 사용 | "한 달 동안 열심히 하셨네요! Pro에서 더 깊은 인사이트를 만나보세요" |
| 월간 리뷰 시도 | "월간 리뷰 풀버전으로 성장 궤적을 확인해보세요"                     |

### 7일 무료 체험

- 신규 가입 시 Pro 7일 체험
- 체험 후 자동 Free로 전환 (결제 정보 불필요)
