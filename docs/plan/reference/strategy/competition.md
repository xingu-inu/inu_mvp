# 경쟁 분석

> 한국 시장 자기개발/습관 앱 경쟁 구도

---

## 경쟁사 분류

| 카테고리        | 앱                        | 특징                     |
| --------------- | ------------------------- | ------------------------ |
| **습관 트래커** | 해빗불, Habitify, Streaks | 단순 체크인, 스트릭 중심 |
| **할 일 관리**  | Todoist, TickTick, Things | 프로젝트/태스크 관리     |
| **생산성**      | Notion, Obsidian          | 범용 노트/데이터베이스   |
| **목표 관리**   | Goalify, Strides          | 목표 + 습관 통합         |
| **AI 코칭**     | Fabulous, Noom            | AI/행동과학 기반         |

---

## 주요 경쟁사 상세

### 해빗불 (한국)

| 항목   | 내용                               |
| ------ | ---------------------------------- |
| 강점   | 한국어 최적화, 깔끔한 UI, 무료     |
| 약점   | 목표 계층 구조 없음, Why 개념 없음 |
| 차별점 | inu는 로드맵 구조 + Why Chain 제공 |

### Todoist

| 항목   | 내용                                  |
| ------ | ------------------------------------- |
| 강점   | 강력한 태스크 관리, 협업 기능         |
| 약점   | 습관/반복 중심 아님, 인생 로드맵 없음 |
| 차별점 | inu는 습관 + 로드맵 + 회고 통합       |

### Notion

| 항목   | 내용                          |
| ------ | ----------------------------- |
| 강점   | 무한 커스터마이징, 범용성     |
| 약점   | 설정 복잡, 모바일 체크인 불편 |
| 차별점 | inu는 원탭 체크인 + 전용 구조 |

### Fabulous

| 항목   | 내용                              |
| ------ | --------------------------------- |
| 강점   | 행동과학 기반, 아름다운 디자인    |
| 약점   | 영어, 비쌈, 커스터마이징 제한     |
| 차별점 | inu는 한국어 + 자유로운 목표 설정 |

### Atoms (Atomic Habits 공식 앱)

| 항목   | 내용                                                              |
| ------ | ----------------------------------------------------------------- |
| 출시   | 2024년 2월 (James Clear 공식)                                     |
| 강점   | Identity-based 습관 형성, 일일 행동심리학 레슨, 브랜드 파워       |
| 약점   | 월 $9.99 (비쌈), 신규 사용자 습관 3개 제한, 로드맵/시간 관리 없음 |
| 차별점 | inu는 5단계 로드맵 + 캘린더 통합 + 1/3 가격 (₩3,900)              |

## 글로벌 AI 코칭 앱 비교

| 앱           | 특징                                   | 가격          | inu 차별점                        |
| ------------ | -------------------------------------- | ------------- | --------------------------------- |
| **Atoms**    | Identity-based 습관, 일일 레슨         | $9.99/월      | 5단계 로드맵으로 큰 그림 제공     |
| **Fabulous** | 행동과학 Journey, 오디오 코칭          | ~$10/월       | 자유도 높음, 사용자가 로드맵 설계 |
| **Noom**     | CBT 기반, AI+인간 코치, 체중 관리 전문 | ~$70/월       | 1/20 가격, 범용 목표 지원         |
| **Habitica** | RPG 게이미피케이션, 파티 시스템        | Free/$4.99/월 | 게임 없이 본질에 집중             |

## 시장 기회

### 글로벌 자기개발 시장

- **2023년**: 514억 달러
- **2032년 예상**: 902억 달러 (CAGR 6.44%)
- 정신 건강/웰빙 인식 증가로 지속 성장

### 한국 시장 특성

- **2023년 앱 시장 성장률**: 25%+ (미국 6%, 일본 1% 대비 압도적)
- **ChatGPT 한국 MAU**: 1,949만 (AI 서비스 수요 급증)
- **습관 앱 특정 통계**: 공개 데이터 부재 → **틈새시장 기회**

### inu 시장 포지셔닝

| 비교 대상 | inu 장점                                   |
| --------- | ------------------------------------------ |
| vs Atoms  | 1/3 가격 (₩3,900 vs $9.99), 시간 관리 통합 |
| vs Noom   | 1/20 가격, 체중 외 모든 목표 지원          |
| vs 해빗불 | 로드맵 구조 + AI 코칭                      |
| vs Notion | 원탭 체크인 + 전용 리뷰                    |
