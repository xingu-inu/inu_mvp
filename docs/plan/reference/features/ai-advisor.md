# AI 어드바이저

> 규칙 기반 알림 + 필요 시 AI 대화 — AI는 "주"가 아닌 "사이드"

---

## 1. 개요

AI 기능은 두 가지로 나뉩니다:

| 구분       | 규칙 기반 알림      | AI 대화     |
| ---------- | ------------------- | ----------- |
| **속도**   | 즉시                | 2-5초 로딩  |
| **비용**   | 무료                | API 비용    |
| **트리거** | 자동 (조건 충족 시) | 사용자 요청 |
| **구현**   | if-then 조건문      | LLM API     |

> **핵심 원칙**: 기본 기능은 규칙 기반으로 빠르게 제공하고,
> 깊은 분석이나 맥락 기반 조언이 필요할 때만 AI를 호출합니다.

## 5. AI 대화 (요청 시, Phase 2+)

사용자가 **버튼을 눌러 요청**할 때만 AI를 호출합니다.

### 5-1. 페이지별 AI 버튼

```
[Roadmap - Goal 상세]
┌─────────────────────────────────┐
│ 🎯 10km 마라톤 완주              │
│ ...                             │
│                                 │
│ [💬 AI와 목표 점검]              │
└─────────────────────────────────┘

[Review - 주간 리뷰]
┌─────────────────────────────────┐
│ 이번 주 달성률: 75%              │
│ ...                             │
│                                 │
│ [💡 AI 인사이트 받기]            │
└─────────────────────────────────┘

[Calendar - 주간 뷰]
┌─────────────────────────────────┐
│ 📅 1월 둘째 주                   │
│ ...                             │
│                                 │
│ [🕐 AI 시간 제안 받기]           │
└─────────────────────────────────┘
```

### 5-2. AI 대화 주제

| 주제        | 설명                          | 진입점            |
| ----------- | ----------------------------- | ----------------- |
| 목표 분해   | 큰 목표를 Phase/Task로 나누기 | Roadmap Goal 상세 |
| 페이스 점검 | 현재 속도가 적절한지          | Roadmap Goal 상세 |
| Why 재탐색  | 동기가 약해졌을 때            | Roadmap Goal 상세 |
| 주간 분석   | 이번 주 패턴 분석             | Review 주간       |
| 영역 밸런스 | 영역별 투자 균형              | Review 월간       |
| 시간 최적화 | Task 시간대 재배치 제안       | Calendar          |
| TODO 제안   | 패턴 기반 다음 할 일 추천     | AI 허브, Review   |
| 자유 대화   | 목표/삶에 대해 이야기         | AI 허브           |

### 5-3. AI 대화 UI (Goal 상세 예시)

```
┌─────────────────────────────────┐
│ 💬 AI와 목표 점검                │
│                                 │
│ "10km 마라톤" 목표에 대해        │
│ 어떤 이야기를 나눠볼까요?        │
│                                 │
│ [🎯 목표를 더 작게 나누고 싶어요] │
│ [📊 지금 페이스가 맞는지 궁금해요]│
│ [💭 왜 이 목표를 세웠는지 잊었어요]│
│ [💬 직접 질문하기]               │
│                                 │
└─────────────────────────────────┘
```

| ------------------ | --------------------------------- | -------- |

## 7. AI 결과 적용

AI가 제안한 내용을 실제로 적용하는 방법:

| AI 제안        | 적용 방식                                      |
| -------------- | ---------------------------------------------- |
| 목표 분해 결과 | [이 Phase/Task 추가하기] 버튼 → Roadmap에 반영 |
| 시간 제안      | [이 시간에 배치하기] 버튼 → Calendar에 반영    |
| TODO 제안      | [Task로 추가하기] 버튼 → 해당 Goal에 추가      |
| 인사이트       | 참고용 (적용 버튼 없음)                        |

## 9. MVP vs Future

| 구분    | 포함 범위                                                           |
| ------- | ------------------------------------------------------------------- |
| MVP     | 규칙 기반 체크인 메시지 (스트릭, 완료 축하)                         |
| Phase 2 | 규칙 기반 확장 + AI 대화 버튼 (Roadmap, Review, Calendar) + AI 허브 |
