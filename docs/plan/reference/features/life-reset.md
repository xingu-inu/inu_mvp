# 인생 재정비 모드

> 삶에 큰 변화가 생겨도 괜찮아요. inu가 함께합니다.

---

## 1. 개요

삶에 큰 변화가 생겼을 때 (이직, 이사, 건강 이슈, 관계 변화 등) 로드맵 전체를 재점검하고 조정하는 특별 모드입니다.

## 3. 트리거

다음 상황에서 AI가 재정비 모드를 제안:

| 신호             | 설명                            |
| ---------------- | ------------------------------- |
| 전체 달성률 급락 | 2주 이상 30% 이하               |
| 다수 Goal 정지   | Active Goal 중 절반 이상 Paused |
| 사용자 요청      | 설정에서 직접 진입              |
| 기분 연속 하락   | 1주일 이상 낮은 기분            |

## 4. 재정비 플로우

### Step 1: 상황 확인

```
🧭 인생 재정비 모드

최근 변화가 있었나요?

[🏢 이직/퇴사]
[🏠 이사/환경변화]
[💔 관계 변화]
[🏥 건강 이슈]
[😔 번아웃]
[🎯 우선순위 변화]
[+ 직접 입력]
```

### Step 2: 로드맵 재점검

각 Active Goal에 대해:

```
🎯 영어 면접 가능 수준

지금 상황에서 이 목표는?

[✅ 그대로 유지]
[⏸ 잠시 멈추기]
[📉 축소/조정]
[❌ 완전히 중단]
```

### Step 3: Direction 재확인

```
🧭 나의 방향

"건강하고 성장하는 삶을 통해 가족과 오래 행복하게"

이 방향이 여전히 맞나요?

[🔥 맞아요]
[🤔 조금 바뀐 것 같아요]
[🔄 완전히 새로 정하고 싶어요]
```

### Step 4: 새 출발

```
🎉 재정비 완료!

• 유지: 3개 목표
• 일시정지: 2개 목표
• 조정: 1개 목표
• 중단: 1개 목표

새로운 마음으로 다시 시작해요.
지금 상황에 맞는 작은 것부터 하나씩.

[오늘 화면으로]
```

---

## 5. 재정비 후 지원

- **회복 모드**: 첫 2주간 AI가 부드러운 톤으로
- **작은 시작**: 가장 쉬운 Task 1개부터 추천
- **기록 연결**: 재정비 이유가 여정에 기록됨

---

## 6. MVP vs Future

| 구분    | 포함 범위                       |
| ------- | ------------------------------- |
| MVP     | 없음 (수동 Goal 조정으로 대체)  |
| Phase 2 | 재정비 모드 기본 플로우         |
| Phase 3 | AI 기반 자동 감지 + 개인화 지원 |
