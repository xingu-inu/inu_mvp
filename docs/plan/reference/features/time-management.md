# 시간 관리 & 캘린더 연동

> 시간대별 Task 배치 + Google Calendar 연동. "지금 뭘 할 차례인지" 명확.

---

## 1. 개요

inu는 Task를 시간 안에 배치하여 "지금 뭘 해야 하는지" 명확하게 보여줍니다. Google Calendar와 연동하여 실제 일정과 함께 관리할 수 있습니다.

## 3. 시간대별 그룹핑

Task를 5+1 시간대로 그룹핑합니다:

| 그룹 | 시간 범위     | 이모지 | 표시 조건                  |
| ---- | ------------- | ------ | -------------------------- |
| 아침 | 6:00 ~ 9:00   | 🌅     | 해당 시간대 Task가 있을 때 |
| 오전 | 9:00 ~ 12:00  | ☀️     | 해당 시간대 Task가 있을 때 |
| 오후 | 12:00 ~ 18:00 | 🌤️     | 해당 시간대 Task가 있을 때 |
| 저녁 | 18:00 ~ 21:00 | 🌙     | 해당 시간대 Task가 있을 때 |
| 밤   | 21:00 ~ 24:00 | 🌑     | 해당 시간대 Task가 있을 때 |
| 자유 | 시간 미지정   | 🕐     | 시간대 설정 안 한 Task     |

---

## 4. Task 시간 설정

| 설정 방식     | 설명                        | 캘린더 표시        |
| ------------- | --------------------------- | ------------------ |
| 시간대 프리셋 | 아침/오전/오후/저녁/밤 선택 | 점선 블록 (플로팅) |
| 특정 시간     | 9:00 같은 정확한 시간       | 실선 블록 (고정)   |
| 미설정        | 시간대 없음                 | 🕐 자유 그룹       |

---

## 5. Action Panel (가치 우선순위)

캘린더 화면 우측에 항상 표시되는 Task 패널:

```
🔥 핵심
  🟢🟣 런닝 30분
  🔵 코딩 1h

⭐ 중요
  🟢 스트레칭 15분
  🔵 영어듣기 15분

📌 기타
  💰 지출리뷰
  ❤️ 부모님연락
```

### 티어 분류 기준

| 티어    | 조건                             |
| ------- | -------------------------------- |
| 🔥 핵심 | 다중 연결 Task, 높은 체크인 빈도 |
| ⭐ 중요 | Active Goal의 주요 Task          |
| 📌 기타 | 나머지 Task                      |

### 인터랙션

- **롱프레스 → 드래그**: 캘린더 그리드에 시간 배치
- **탭**: Task 상세 바텀시트
- **필터**: Area별 필터링

---

## 6. Google Calendar 연동

### 통합 뷰

- inu Task (실선 블록) + Google Calendar 이벤트 (점선, 회색)
- 한 화면에서 전체 일정 확인

### 연동 기능

| 기능         | 설명                        |
| ------------ | --------------------------- |
| 읽기         | Google Calendar 이벤트 표시 |
| 충돌 감지    | 회의 시간과 Task 충돌 알림  |
| 빈 시간 제안 | "수요일 저녁이 비어있어요"  |

### 연동 설정

설정 > Google Calendar 연동에서:

- 연동할 캘린더 선택
- 동기화 주기 설정
- 표시 옵션 (색상, 상세 수준)

---

## 7. 빈 시간 제안

캘린더에서 빈 시간을 감지하고 제안:

```
💡 수요일 저녁이 비어있어요.
   Task를 배치해볼까요?
```
