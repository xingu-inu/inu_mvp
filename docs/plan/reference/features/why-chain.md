# Why Chain (동기 사슬)

> 모든 레벨에 "왜?"를 부여. Task에서 위로 올라가면 인생의 근본 이유가 보입니다.

---

## 1. 개요

Why Chain은 Direction, Area, Goal, Phase, Task — 모든 레벨에 각각 "왜?"를 부여하는 시스템입니다. 아래에서 위로 올라가면 내 인생의 근본적인 이유가 드러납니다.

## 3. 5단계 Why Chain

```
Direction  → "나는 [___]을 통해 [___]하는 삶을 살고 싶다" (Why의 근원) ⭐ 필수
Area.why   → "이 영역이 내 인생에서 왜 중요한가" (선택)
Goal.why   → "이 목표를 왜 달성하고 싶은가" (선택)
Phase.why  → "이 단계를 왜 먼저 해야 하는가" (선택)
Task.why   → "이 행동을 왜 선택했는가 (왜 효과적인가)" (선택)
```

> **MVP 단순화**: Direction만 필수 입력, 나머지 Why는 선택사항입니다.
> 처음엔 가볍게 시작하고, 필요할 때 Why를 추가하면 됩니다.

### 예시

```
✅ 매일 30분 러닝 (Task)
   왜 이 행동을? "유산소가 체력과 집중력을 동시에 올린다"
        ↑
📍 Phase 1: 기초 체력 만들기 (Phase)
   왜 이 단계부터? "기초 체력이 있어야 5km를 시작할 수 있으니까"
        ↑
🎯 10km 달리기 완주 (Goal)
   왜 이 목표를? "기초체력이 모든 활동의 기반이다"
        ↑
💪 건강 (Area)
   왜 이 영역이 중요한가? "오래 건강하게 살고 싶다"
        ↑
🧭 나의 방향 (Direction)
   "건강하고 당당한 삶을 통해 가족과 오래 행복하게"
```

---

## 4. 왜 중요한가

| 레벨          | 효과                                                |
| ------------- | --------------------------------------------------- |
| **Task.why**  | 행동이 효과적인 이유를 알면 → 납득 → 실천 의지 ↑    |
| **Phase.why** | "왜 지금 이 단계인지" → 로드맵에서의 현재 위치 명확 |
| **Goal.why**  | 동기 떨어졌을 때 "왜 시작했는지" 상기               |
| **Area.why**  | 근본적인 삶의 가치까지 거슬러 올라가 초심 회복      |

---

## 5. Why 간격 반복 (Spaced Repetition)

Why는 한 번 적어두면 잊혀집니다. 에빙하우스 망각곡선 기반으로 주기적으로 상기시킵니다:

| 시점   | 방식                      | 간격 |
| ------ | ------------------------- | ---- |
| Day 1  | Goal 생성 시 Why 작성     | —    |
| Day 2  | 체크인 시 Why 한 줄 표시  | 1일  |
| Day 4  | 체크인 시 Why 한 줄 표시  | 2일  |
| Day 8  | AI "Why 회상" 카드        | 4일  |
| Day 15 | 주간 리뷰에서 Why 재확인  | 7일  |
| Day 30 | **Why 온도 체크**         | 15일 |
| Day 60 | 풀스크린 Direction 재확인 | 30일 |

## 6. Why 온도 체크

일정 주기마다 "이 이유가 아직 마음에 와닿는지" 확인합니다:

```
── Why 온도 체크 ──

"영어 실력 향상"의 이유:
"해외 취업을 준비하고 있어서"

이 이유가 아직 마음에 와닿나요?

[🔥 많이]  [🙂 조금]  [😐 별로]

→ "별로" 선택 시 → "Why를 새로 정해볼까요?" → Why 재탐색 플로우
```

- 온도가 낮아진 Goal에 대해 AI가 "방향 점검" 제안
- 이력이 쌓이면 AI가 동기 저하 패턴 감지

## 8. MVP UX 플로우

### 8-1. Direction Why (MVP 필수)

**진입점**: 온보딩 Step 3 (Direction 설정)

**UI**:

```
┌─────────────────────────────────────┐
│                                     │
│  🧭 나의 방향을 정해볼까요?          │
│                                     │
│  나는                               │
│  ┌─────────────────────────────┐   │
│  │ 건강하고 당당한 삶           │   │
│  └─────────────────────────────┘   │
│  을 통해                            │
│  ┌─────────────────────────────┐   │
│  │ 가족과 오래 행복하게         │   │
│  └─────────────────────────────┘   │
│  살고 싶다.                         │
│                                     │
│           [다음 →]                  │
│                                     │
└─────────────────────────────────────┘
```

- **저장**: Profile에 표시, 언제든 수정 가능
- **수정**: Profile > Direction 섹션 > [수정] 버튼

### 8-2. Goal/Phase/Task Why (Phase 2)

**진입점**: 각 생성 화면의 "Why 추가 (선택)" 버튼

**Goal 생성 시**:

```
┌─────────────────────────────────────┐
│ 새 Goal 만들기                      │
│                                     │
│ 🎯 목표 이름                        │
│ ┌─────────────────────────────┐   │
│ │ 10km 달리기 완주              │   │
│ └─────────────────────────────┘   │
│                                     │
│ [+ Why 추가 (선택)]                 │
│                                     │
│           [만들기]                  │
└─────────────────────────────────────┘
```

**Why 입력 바텀시트**:

```
┌─────────────────────────────────────┐
│ 💭 이 목표를 왜 달성하고 싶나요?    │
│                                     │
│ ┌─────────────────────────────┐   │
│ │ 기초체력이 모든 활동의 기반   │   │
│ │ 이다                         │   │
│ └─────────────────────────────┘   │
│                                     │
│ 💡 예시: "자신감을 갖고 싶어서"     │
│                                     │
│           [저장]                    │
└─────────────────────────────────────┘
```

**Task 카드 표시** (Why 있을 때만):

```
┌─────────────────────────────────────┐
│ 🏃 매일 30분 러닝        🟢🔥12    │
│ └ 기초 체력(Phase1) · 💪 건강      │
│ 💭 "유산소가 체력과 집중력을 올린다"│  ← 탭하면 접기/펼치기
│    [ ✅ Done ]   [ ⏭ Skip ]       │
└─────────────────────────────────────┘
```
