# 공통 UI 컴포넌트

> 앱 전체에서 재사용되는 UI 컴포넌트

---

## 1. Area 칩/배지

영역 식별을 위한 색상 칩

```
🟢  💪 건강
🔵  📈 커리어
🟣  🧘 멘탈
```

### 속성

| 속성  | 설명                    |
| ----- | ----------------------- |
| color | Area별 고유 색상        |
| emoji | Area 이모지             |
| name  | Area 이름 (선택적 표시) |

### 다중 연결 표시

Task가 여러 Area에 연결된 경우:

```
🟢🟣 매일 30분 러닝
```

---

## 2. 스트릭 배지

연속 완료 카운터

```
🔥 12
```

### 표시 규칙

| 조건      | 표시            |
| --------- | --------------- |
| 스트릭 0  | 표시 안 함      |
| 스트릭 1+ | 🔥 + 숫자       |
| 5의 배수  | 강조 애니메이션 |

---

## 3. Phase 인디케이터

Goal 내 Phase 진행 상태

```
Phase 1 ●━━ Phase 2 ○━━ Phase 3 ○
```

### 상태

| 상태 | 표시            |
| ---- | --------------- |
| 완료 | ● (채워진 원)   |
| 현재 | ★ 또는 ● + 강조 |
| 미래 | ○ (빈 원)       |

---

## 4. 진행률 바

```
▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░  3/5 완료
████████████████░░░░  78%
```

### 속성

| 속성  | 설명                     |
| ----- | ------------------------ |
| value | 현재 값                  |
| max   | 최대 값                  |
| color | Area 색상 또는 기본      |
| label | 숫자 표시 (3/5 또는 78%) |

---

## 5. 기분 선택기

5단계 이모지

```
😫   😕   😐   🙂   😄
```

### 사용 화면

- Today (체크인 완료 후)
- Review (회고)
- 저널 (자유 기록)

---

## 6. AI 인사이트 카드

```
┌─────────────────────────────────┐
│ 💡 AI 코치의 한마디:             │
│ "독서 스트릭 5일째! 이번 달에    │
│  목표한 2권 중 1권은 거뜬하겠네요"│
│                                 │
│         [자세히 이야기하기 →]     │
└─────────────────────────────────┘
```

### 구성

| 요소   | 설명               |
| ------ | ------------------ |
| 아이콘 | 💡 또는 🤖         |
| 제목   | "AI 코치의 한마디" |
| 내용   | 인사이트 텍스트    |
| 액션   | 선택적 CTA 버튼    |

---

## 7. 필터/토글

```
[Active ▼]  [전체]  [Backlog]

[🌳|🃏]  뷰 토글

[주간|월간]  기간 토글
```
