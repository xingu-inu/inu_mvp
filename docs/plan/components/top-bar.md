# Top Bar (상단 바) 컴포넌트

> 모든 화면에서 공통으로 사용되는 상단 네비게이션 바

---

## 개요

상단 바는 **모든 화면에서 일관되게 표시**되는 핵심 네비게이션 요소입니다.

- 모바일: 햄버거 메뉴 + 로고 + 퀵 액션
- 데스크톱: 로고 + 퀵 액션 + 프로필

---

## 레이아웃

### Mobile (375px)

```
┌─────────────────────────────────────┐
│  [≡]      inu      [🔍] [📥] [🤖] │
│  ↑         ↑          ↑    ↑    ↑  │
│  햄버거   로고      검색 인박스 AI │
│  24px    중앙       24px 24px 24px │
│  ← 16px →                ← 16px → │
└─────────────────────────────────────┘
높이: 44px
```

### Desktop (1024px+)

```
┌────────────────────────────────────────────────────────────────┐
│  [inu]                              [🔍] [📥] [🤖] [👤 지은]  │
│   ↑                                   ↑    ↑    ↑      ↑      │
│  로고                               검색 인박스 AI  프로필    │
│  ← 24px →                                         ← 24px →   │
└────────────────────────────────────────────────────────────────┘
높이: 56px
```

---

## 요소별 상세

### 1. 햄버거 메뉴 [≡] (모바일 전용)

- 위치: 좌측
- 크기: 44x44px (터치 영역)
- 아이콘: 24x24px
- 동작: 탭 시 슬라이드 패널 열기
- 내용: 프로필 + 설정 메뉴

### 2. 로고 [inu]

- 위치: 모바일 = 중앙, 데스크톱 = 좌측
- 크기: 폰트 18px Bold (모바일), 20px Bold (데스크톱)
- 색상: Primary 색상
- 동작: 탭 시 Home 화면으로 이동

### 3. 검색 [🔍]

- 위치: 우측 영역
- 크기: 44x44px (터치 영역), 아이콘 24x24px
- 동작:
  - 모바일: 전체 화면 오버레이
  - 데스크톱: 드롭다운 오버레이 또는 `Cmd/Ctrl + K`
- 상태: 검색 중일 때 Primary 색상

### 4. 인박스 [📥]

- 위치: 우측 영역
- 크기: 44x44px (터치 영역), 아이콘 24x24px
- 배지: 미정리 아이템 수 (빨간색 원, 최대 "9+")
- 동작:
  - 모바일: 바텀시트 (화면 80%)
  - 데스크톱: 우측 패널 또는 모달
- 상태: 새 아이템 있으면 배지 표시

### 5. AI Hub [🤖]

- 위치: 우측 영역
- 크기: 44x44px (터치 영역), 아이콘 24x24px
- 동작: AI Hub 전체 화면으로 이동
- 상태: AI Hub 화면일 때 Primary 색상

### 6. 프로필 [👤] (데스크톱 전용)

- 위치: 최우측
- 크기: 클릭 영역 100px+
- 표시: 아이콘 + 이름 ("👤 지은")
- 동작: 탭 시 드롭다운 메뉴
- 드롭다운 내용:
  - 사용자 이름
  - 설정
  - 통계
  - 로그아웃

## 스타일

```
상단 바:
- 배경: white
- 그림자: 0 1px 3px rgba(0,0,0,0.06)
- z-index: 100 (항상 최상단)
- position: fixed (스크롤 시 고정)

아이콘:
- 기본: Gray 600
- 활성/호버: Primary 색상
- 배지: #FF3B30 (빨간색)

터치/클릭:
- 터치 영역: 최소 44x44px
- 호버: 배경 Gray 50 (데스크톱)
- 탭: 배경 Gray 100
```

- 모든 아이콘에 aria-label 제공
- 키보드 네비게이션 지원 (Tab 순서)

- 고대비 모드 지원
