# 네비게이션 시스템

> 앱 전체의 통합 네비게이션 구조

---

## 개요

inu 앱의 네비게이션은 **일관된 접근성**을 위해 통합 설계되었습니다.

| 플랫폼   | 주요 네비게이션     | 보조 네비게이션 |
| -------- | ------------------- | --------------- |
| 모바일   | 하단 탭 바 (3탭)    | 상단 바         |
| 데스크톱 | 좌측 사이드바 (4개) | 상단 바         |

> **네이밍**: 메인 화면은 "홈"으로 통일 (🏠 아이콘)
> **Calendar 통합**: Calendar는 Home에 흡수되어 Day/Week/Month 뷰로 제공

## 1. 하단 탭 바 (모바일)

**3탭 구조**

```
┌──────────┬──────────┬────────────┐
│  🏠 홈    │ 🗺 로드맵 │ 📊 리뷰   │
│  (Do+When)│(Plan:What)│(Check+Act)│
└──────────┴──────────┴────────────┘
높이: 56px + Safe Area (34px)
```

| 탭        | PDCA      | 역할                         | 화면                                  |
| --------- | --------- | ---------------------------- | ------------------------------------- |
| 🏠 홈     | Do + When | 체크인 + Day/Week/Month 일정 | [Home](../screens/today/spec.md)      |
| 🗺 로드맵 | Plan:What | 인생 로드맵                  | [Roadmap](../screens/roadmap/spec.md) |
| 📊 리뷰   | Check+Act | 회고 & 조정                  | [Review](../screens/review/spec.md)   |

### 스타일

```
하단 탭 바:
- 높이: 56px + Safe Area
- 배경: white
- 그림자: 0 -1px 3px rgba(0,0,0,0.06)
- border-top: 1px solid Gray 100

탭 아이템:
- 아이콘: 24x24px
- 라벨: 11px
- 간격: 아이콘-라벨 4px

활성 상태:
- 아이콘 + 라벨: Primary 색상

비활성 상태:
- 아이콘 + 라벨: Gray 500
```

## 2. 상단 바

모든 화면에서 공통으로 표시됩니다.

### 모바일

```
┌─────────────────────────────────────┐
│  [≡]      inu      [🔍] [📥] [🤖] │
└─────────────────────────────────────┘
높이: 44px
```

### 데스크톱

```
┌────────────────────────────────────────────────────────────────┐
│  [inu]                              [🔍] [📥] [🤖] [👤 지은]  │
└────────────────────────────────────────────────────────────────┘
높이: 56px
```

| 요소        | 모바일 | 데스크톱 | 동작              |
| ----------- | ------ | -------- | ----------------- |
| [≡] 햄버거  | ✓      | -        | 슬라이드 메뉴     |
| [inu] 로고  | 중앙   | 좌측     | Home으로 이동     |
| [🔍] 검색   | ✓      | ✓        | 오버레이/드롭다운 |
| [📥] 인박스 | ✓      | ✓        | 바텀시트/패널     |
| [🤖] AI Hub | ✓      | ✓        | 전체 화면 이동    |
| [👤] 프로필 | -      | ✓        | 드롭다운 메뉴     |

## 4. 화면별 네비게이션 적용

| 화면         | 모바일                    | 데스크톱                    |
| ------------ | ------------------------- | --------------------------- |
| **Home**     | 상단바 + 하단탭(\*홈)     | 상단바 + 사이드바(\*홈)     |
| **Roadmap**  | 상단바 + 하단탭(\*로드맵) | 상단바 + 사이드바(\*로드맵) |
| **Review**   | 상단바 + 하단탭(\*리뷰)   | 상단바 + 사이드바(\*리뷰)   |
| **Settings** | 자체 헤더                 | 상단바 + 사이드바(\*설정)   |
| **Search**   | 전체 화면 오버레이        | 드롭다운 오버레이           |
| **Inbox**    | 바텀시트 (80%)            | 우측 패널/모달              |
| **AI Hub**   | 상단바 + 하단탭           | 상단바 + 사이드바           |
| **Profile**  | 슬라이드 패널             | 드롭다운                    |

## 5. 딥링크 지원

| 경로              | 화면                         |
| ----------------- | ---------------------------- |
| /home             | Home 화면 (Day 뷰)           |
| /home?view=week   | Home 화면 (Week 뷰)          |
| /home?view=month  | Home 화면 (Month 뷰)         |
| /roadmap          | Roadmap 화면                 |
| /roadmap/goal/:id | Goal 상세                    |
| /calendar         | → /home?view=week 리다이렉트 |
| /review           | Review 화면                  |
| /ai               | AI Hub 화면                  |
| /settings         | 설정 화면                    |
