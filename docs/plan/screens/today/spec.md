# Home (홈) 페이지

> 서비스에서 가장 중요한 화면. Day/Week/Month 3가지 뷰로 체크인 + 일정 + 일상을 한 곳에서 관리.

---

## 1. 개요

| 항목              | 내용                                                       |
| ----------------- | ---------------------------------------------------------- |
| **목적**          | 오늘 할 Task 체크인 + 주간/월간 일정 관리를 통합 제공      |
| **PDCA 역할**     | **Do** (실행) + **Plan:When** (시간 배치)                  |
| **해결하는 문제** | "오늘 뭘 해야 하지?" + "빈 시간에 뭘 하지?"                |
| **경로**          | `/home` (Day, 기본), `/home?view=week`, `/home?view=month` |

---

## 2. 진입점 & 네비게이션

- **진입**: 앱 실행 시 기본 화면, 하단 탭 "홈"
- **이동 가능**: Roadmap (Goal 상세), Review (통계)
- **기존 `/calendar` 경로**: `/home?view=week`으로 리다이렉트

---

## 3. 뷰 모드

### Day 뷰 (기본 — 앱 열면 이것)

```
┌─────────────────────────────────┐
│ 2월 4일 화요일           [일][주][월]│ ← 날짜 + 뷰 전환
│                                 │
│ ┌─ 미니 월간 캘린더 (접기 가능) ─┐│
│ │ 일 월 화 수 목 금 토          ││
│ │          1  2  3  4           ││
│ │  🟢🔵  ●  ●  ★              ││ ← Area 컬러 dot
│ └───────────────────────────────┘│
│                                 │
│ ── 3/5 완료 ▓▓▓▓▓▓░░░ ──      │ ← 진행률 바
│                                 │
│ ☀️ 아침                         │
│ ┌ 🏃 매일 30분 걷기  🔥12      ┐│
│ │ 💪 건강 · 기초체력            ││ ← Area칩 + Goal경로
│ │ [ ✅ Done ] [ ⏭ Skip ]       ││
│ └───────────────────────────────┘│
│                                 │
│ 📌 일상                         │ ← 일상 태스크 섹션
│ ┌ 🛒 장보기                    ┐│
│ │ [ ✅ Done ] [ ⏭ Skip ]       ││
│ └───────────────────────────────┘│
│                                 │
│ ── 오늘 하루 ──                 │
│ 😫 😕 😐 🙂 😄                  │ ← 기분
│ [한줄 회고 입력...]             │
│                                 │
│            [＋]                  │ ← 퀵 추가
└─────────────────────────────────┘
```

### Week 뷰 (`/home?view=week`)

- 7일 그리드 + 시간대 행
- Area 컬러 태스크 필
- 미배치 태스크 ActionPanel (하단/사이드)

### Month 뷰 (`/home?view=month`)

- 월간 달력 + 날짜별 컬러 dot
- 날짜 탭 → 해당일 태스크 표시

| HOME-013 | 월간 뷰              | 컬러 모자이크                               | MVP      |
| HOME-014 | Action Panel         | 미배치 Task 리스트 (Week/Month)             | MVP      |
| HOME-015 | 퀵 추가              | Day 뷰에서 빠른 Task 추가 (일상 기본값)     | MVP      |

### AI 한마디 vs AI 넛지 카드 차이

| 구분       | AI 한마디 (HOME-006)            | AI 넛지 카드 (HOME-009)                 |
| ---------- | ------------------------------- | --------------------------------------- |
| **트리거** | 체크인 완료 직후                | 화면 진입 시 (조건 충족 시)             |
| **위치**   | 완료된 Task 카드 하단           | Day 뷰 상단                             |
| **내용**   | "스트릭 12일째!" 등 즉각 피드백 | "오늘 아직 운동 안 했어요" 등 사전 제안 |
| **목적**   | 즉각적 동기부여                 | 행동 유도 넛지                          |

## 5. 체크인 카드 구성

### 목표 연결 태스크

```
┌─────────────────────────────────┐
│ 🏃 매일 30분 걷기  🟢🔥12 30분 │ ← 이모지+이름 / Area칩+스트릭+시간
│ └ 기초 체력(Phase1) · 💪 건강   │ ← Phase·Goal·Area 경로
│ 💭 "유산소가 기초 체력의 핵심"   │ ← Task.why
│    [ ✅ Done ]   [ ⏭ Skip ]    │ ← 액션 버튼
└─────────────────────────────────┘
```

### 일상 태스크 (goal_id === null)

```
┌─────────────────────────────────┐
│ 🛒 장보기            📌 일상   │ ← 이모지+이름 / 일상칩
│    [ ✅ Done ]   [ ⏭ Skip ]    │ ← 액션 버튼 (WhyChain 없음)
└─────────────────────────────────┘
```

## 8. 사용자 시나리오

### 시나리오: 아침 체크인 (Day 뷰)

1. 지은이 아침 8시에 앱을 연다
2. Day 뷰: 미니 월간 캘린더 + 오늘 할 일 5개
3. "아침" 시간대의 "매일 30분 걷기" Done 탭
4. 스트릭 12 → 13, 파티클 효과
5. "📌 일상" 섹션의 "장보기" Done 탭
6. 진행률 바 업데이트

### 시나리오: 주간 일정 확인 (Week 뷰)

1. 뷰 토글에서 "주" 선택
2. 7일 그리드 + 시간대별 태스크 표시
3. ActionPanel에서 미배치 태스크 확인

## 11. 데이터 요구사항

### 표시 데이터

- Day: 오늘 날짜의 Active Goal → Active Phase → Task + 일상 Task
- Week: 해당 주의 모든 Task (시간대별)
- Month: 해당 월의 모든 Task (날짜별 dot)
- 각 Task의 반복 주기에 맞는 것만 필터
- Task별 스트릭 카운터

### 사용자 입력

- Done / Skip 선택
- 기분 (1-5)
- 한 줄 메모 (선택)

### 저장 데이터

- CheckIn 레코드 (task_id, date, status, completed_at)
- DailyReflection 레코드 (date, mood, summary)
