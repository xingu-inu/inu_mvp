## 인터랙션

### 탭/클릭

| 요소                 | 동작                               |
| -------------------- | ---------------------------------- |
| Done 버튼            | Task 완료 → 스트릭+1 → 파티클 효과 |
| Skip 버튼            | Task Skip → 스트릭 유지 → 회색     |
| 뷰 토글 [일\|주\|월] | Day/Week/Month 뷰 전환             |
| 미니 캘린더 날짜     | 해당 날짜로 이동                   |
| [접기] 버튼          | 미니 캘린더 접기/펼치기            |
| [＋] FAB             | 퀵 추가 시트 열기                  |
| 하단 탭              | 해당 화면으로 네비게이션           |

### 스와이프

| 방향              | 동작                  |
| ----------------- | --------------------- |
| 미니 캘린더 좌/우 | 이전/다음 월          |
| Week/Month 좌/우  | 이전/다음 주(월) 이동 |
