## 4. 기능 목록

| ID       | 기능명             | 설명              | 우선순위 |
| -------- | ------------------ | ----------------- | -------- |
| AUTH-001 | 이메일 회원가입    | 이메일 + 비밀번호 | MVP      |
| AUTH-002 | 이메일 로그인      | 이메일 + 비밀번호 | MVP      |
| AUTH-003 | Google 소셜 로그인 | OAuth             | MVP      |
| AUTH-004 | Apple 소셜 로그인  | OAuth (iOS)       | Phase 2  |
| AUTH-005 | 비밀번호 재설정    | 이메일 인증       | MVP      |
| AUTH-006 | 자동 로그인        | 토큰 저장         | MVP      |

---

## 5. 사용자 시나리오

### 시나리오: 신규 가입

1. 앱 실행 → 랜딩 페이지
2. "시작하기" 탭
3. 회원가입 화면 → Google로 계속하기
4. Google 계정 선택
5. 인증 완료 → Onboarding으로 이동

### 시나리오: 기존 사용자 로그인

1. 앱 실행 → 랜딩 페이지
2. "로그인" 탭
3. 이메일 + 비밀번호 입력
4. 로그인 → Today 화면으로 이동
