# AI 허브 (AI 코치) 페이지

> AI와 대화하고, 인사이트를 모아보고, 제안을 받는 전용 공간

---

## 1. 개요

| 항목              | 내용                                  |
| ----------------- | ------------------------------------- |
| **목적**          | AI 기능을 모아서 접근하는 허브        |
| **진입**          | 상단 바 🤖 아이콘                     |
| **해결하는 문제** | "AI한테 물어보고 싶은데 어디서 하지?" |

---

## 2. 진입점 & 네비게이션

- **진입**: 상단 바 🤖 AI 아이콘, 또는 각 페이지 AI 버튼에서 "더 알아보기"
- **이동 가능**: Roadmap (Goal 추가 시), Calendar (시간 배치 시), Review (인사이트 연결)

## 5. 기능별 상세

### 5-1. 자유 대화 (AI-001)

목표나 삶에 대해 자유롭게 AI와 이야기합니다.

```
┌─────────────────────────────────┐
│ 💬 자유 대화                     │
│                                 │
│ 무엇이든 물어보세요.            │
│ 목표, 방향, 고민... 함께 생각해요│
│                                 │
│ ┌─────────────────────────────┐ │
│ │ 요즘 운동을 자꾸 미루게 되는  │ │
│ │ 데 왜 그럴까요?              │ │
│ └─────────────────────────────┘ │
│                      [보내기 →] │
│                                 │
│ ── 또는 주제 선택 ─────────────  │
│                                 │
│ [🎯 목표 점검] [💭 방향 탐색]   │
│ [😔 슬럼프 극복] [✨ 동기 찾기] │
│                                 │
└─────────────────────────────────┘
```

### 5-2. 주간 인사이트 (AI-002)

이번 주 데이터를 분석해서 인사이트를 제공합니다.

```
┌─────────────────────────────────┐
│ 💡 이번 주 인사이트              │
│                                 │
│ ⏳ 분석 중...                    │
│                                 │
│ ─────────────────────────────── │
│                                 │
│ 📊 이번 주 요약                  │
│                                 │
│ • 달성률 78% (↑12% vs 지난주)   │
│ • 아침 시간대 체크인 85% 성공    │
│ • 저녁 시간대가 가장 어려웠어요  │
│                                 │
│ 💡 제안                          │
│                                 │
│ "저녁 운동을 아침으로 옮기면     │
│  성공률이 올라갈 것 같아요.     │
│  아침에 운동하는 습관이 이미    │
│  잘 잡혀있거든요!"              │
│                                 │
│ [🕐 시간 변경 적용하기]          │
│                                 │
└─────────────────────────────────┘
```

### 5-3. TODO 제안 (AI-003)

패턴을 분석해서 다음에 할 일을 제안합니다.

```
│                                 │
│ 지금까지의 패턴을 보고          │

│                                 │

│                                 │

│                                 │
│ ┌─────────────────────────────┐ │
│ │ 🏃 5km 러닝 도전             │ │
│ │ Phase 2 준비 단계            │ │
│ │        [+ Task로 추가하기]   │ │
│ └─────────────────────────────┘ │
│                                 │
│ ┌─────────────────────────────┐ │
│ │ 📖 러닝 자세 영상 보기        │ │
│ │ 부상 방지                    │ │
│ │        [+ Task로 추가하기]   │ │
│ └─────────────────────────────┘ │
│                                 │
└─────────────────────────────────┘
```

### 5-4. 타임라인 최적화 (AI-004)

```

│ 🕐 타임라인 최적화               │
│                                 │
│ 현재 시간 배치를 분석했어요     │
│                                 │
│ ─────────────────────────────── │
│                                 │
│ 📊 현재 패턴                     │
│                                 │
│ • 아침: 운동 (성공률 85%)       │
│ • 점심: 학습 (성공률 60%)       │
│ • 저녁: 독서 (성공률 40%)       │
│                                 │
│ 💡 제안                          │
│                                 │
│ ┌─────────────────────────────┐ │
│ │ 📖 독서 → 아침으로 이동       │ │
│ │ 이유: 아침 집중력이 높아요    │ │
│ │          [시간 변경 적용]    │ │
│ └─────────────────────────────┘ │
│                                 │
│ ┌─────────────────────────────┐ │
│ │ 📚 학습 → 저녁으로 이동       │ │
│ │ 이유: 퇴근 후 여유 시간 활용  │ │
│ │          [시간 변경 적용]    │ │
│ └─────────────────────────────┘ │
│                                 │
│         [전체 적용하기]         │
│                                 │
└─────────────────────────────────┘
```

## 6. AI 결과 적용 플로우

AI 제안을 실제로 적용하는 과정:

```
AI 제안 → [적용 버튼] → 확인 모달 → 적용 완료
                              │
                              ▼
                    해당 페이지로 이동
                    (Roadmap/Calendar)
```

| AI 제안   | 적용 버튼         | 결과                 |
| --------- | ----------------- | -------------------- |
| TODO 제안 | [Task로 추가하기] | Roadmap에 Task 추가  |
| 시간 변경 | [시간 변경 적용]  | Calendar에 반영      |
| 목표 분해 | [Phase 추가하기]  | Roadmap에 Phase 추가 |

## 7. 사용자 시나리오

### 시나리오: TODO 제안 받기

1. 상단 바 🤖 탭
2. "TODO 제안 받기" 선택
3. AI가 현재 진행 상황 분석
4. "5km 러닝 도전" Task 제안
5. [Task로 추가하기] 탭
6. "🎯 10km 마라톤" Goal에 Task 추가됨
7. Roadmap으로 이동해서 확인

## 10. 데이터 요구사항

### 표시 데이터

- 사용자의 전체 Goal, Phase, Task 현황
- 체크인 히스토리 (패턴 분석용)
- 최근 AI 대화 히스토리

### 사용자 입력

- 자유 대화 텍스트
- AI 제안 적용 여부

### 저장 데이터

- AIConversation 레코드 (type, content, created_at)
- AI 제안 적용 이력
