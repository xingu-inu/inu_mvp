# Roadmap (로드맵) 페이지

> 인생의 큰 그림을 한눈에 보고 관리

---

## 1. 개요

| 항목              | 내용                                               |
| ----------------- | -------------------------------------------------- |
| **목적**          | 인생 로드맵 시각화 및 관리                         |
| **PDCA 역할**     | **Plan (What)** - 무엇을 할지 계획                 |
| **해결하는 문제** | "내 인생에서 뭘 하고 싶지?", "지금 어디까지 왔지?" |

## 2. 진입점 & 네비게이션

- **진입**: 하단 탭 "로드맵"
- **이동 가능**: Goal 상세, Today (Task 확인), Calendar (시간 배치)

## 3. 화면 구성

### 뷰 전환

`[🗺️|🌳|🃏]` → 맵 뷰(기본) | 트리 뷰 | 카드 뷰

### 3-1. 맵 뷰 (기본, 위→아래 다이어그램)

Direction을 루트로 Area → Goal → Phase → Task 계층을 다이어그램으로 시각화

```
┌─────────────────────────────────────────────────────────┐
│ 나의 인생 로드맵                    [🗺️|🌳|🃏] [+]     │
│                                                         │
│ [Active ▼]  [전체]  [Backlog]                          │
│                                                         │
│              ┌─────────────┐                            │
│              │ 🌟 Direction │                           │
│              │  (인생 방향)  │                           │
│              └──────┬──────┘                            │
│     ┌───────────────┼───────────────┐                   │
│     ▼               ▼               ▼                   │
│ ┌────────┐    ┌────────┐    ┌────────┐                 │
│ │💪 건강 │    │📈 커리어│    │💰 재정 │  ...           │
│ └───┬────┘    └───┬────┘    └────────┘                 │
│     │             │                                     │
│     ▼             ▼                                     │
│ ┌────────┐   ┌─────────┐                               │
│ │🎯 10km │   │🎯 영어  │                               │
│ │ 달리기  │   │  면접   │                               │
│ └───┬────┘   └────┬────┘                               │
│     │             │                                     │
│ ┌───┴───┐    ┌────┴────┐                               │
│ │Phase 1│    │✅ 뉴스  │                               │
│ │기초체력│    │✅ 쉐도잉│                               │
│ └───┬───┘    └─────────┘                               │
│     │                                                   │
│ ┌───┴────┐                                             │
│ │✅ 러닝 │                                             │
│ │✅ 스트레칭│                                           │
│ └────────┘                                             │
│                                          [핀치: 줌/팬] │
├─────────┬─────────┬─────────┬───────────────────────────┤
│  오늘   │●로드맵  │ 캘린더  │ 리뷰                      │
└─────────┴─────────┴─────────┴───────────────────────────┘
```

**맵 뷰 인터랙션**:

| 제스처        | 동작                                |
| ------------- | ----------------------------------- |
| 노드 탭       | 해당 항목 상세 페이지 이동          |
| 노드 롱프레스 | 빠른 액션 메뉴 (편집/삭제/상태변경) |
| 핀치 줌       | 확대/축소                           |
| 드래그        | 화면 이동 (팬)                      |
| 더블 탭       | 해당 노드 중심으로 포커스           |

### 3-2. 트리 뷰 (토글 🌳)

```

│   │                             │
│   ▼ 🎯 10km 마라톤 완주     D-90│
│   │  ●━━○━━○ (Phase 1/3)        │
│   │                             │
│   │  ▼ Phase 1: 기초 체력 ← 현재│
│   │    ├─ ✅ 매일 30분 러닝  🔥12│
│   │    └─ ✅ 스트레칭 15분   🔥5 │
│   │                             │
│   │  ▸ Phase 2: 5km (접힘)      │
│   │  ▸ Phase 3: 10km (접힘)     │
│   │                             │

│ ▸ 📈 커리어 ─────── Active 2    │
│ ▸ 💰 재정 ──────────── BL 1     │
└─────────────────────────────────┘
```

## 5. Goal 상세 페이지

```
┌─────────────────────────────────┐
│ ← 뒤로                          │
│                                 │
│ 🎯 10km 마라톤 완주              │
│ 💪 건강                          │
│ [🟢 Active ▾]      기한: 2026.06.15│  ← 탭하면 상태 변경
│                                 │
│ ── 왜? ────────────────────────│
│ 💭 "꾸준한 운동 습관으로 건강한   │
│     몸을 만들고 싶으니까"        │
│       ↑ 💪 건강 영역             │
│       "가족과 오랫동안 함께하고 싶다"│
│                                 │
│ ── Phase ──────────────────────│
│ Phase 1 ●━━ Phase 2 ○━━ Phase 3 ○│
│                                 │
│ ▼ Phase 1: 기초 체력 만들기 (현재)│
│   💭 "기초 체력이 있어야 달릴 수 있다"│
│   ├── ✅ 매일 30분 걷기     🔥12│
│   └── ✅ 스트레칭 15분      🔥5 │
│   ── 달성률: 75% ───────────   │
│                                 │
│  [+ Task 추가]   [AI와 목표 점검] │
└─────────────────────────────────┘
```

### 5-1. Goal 상태 관리 (ROAD-011)

**진입점**: Goal 상세 페이지 > 상단 상태 배지 탭

**상태 선택 바텀시트**:

```
┌─────────────────────────────────┐
│ 상태 변경                        │
│                                 │
│ [🟢 Active]      ← 현재         │
│ 진행 중인 목표                   │
│                                 │
│ [⏸️ Paused]                      │
│ 일시 중지 (스트릭 유지)           │
│                                 │
│ [📋 Backlog]                     │
│ 나중에 할 목표                   │
│                                 │
│ [✅ Completed]                   │
│ 달성 완료!                       │
│                                 │
│ ── Phase 2 ─────────────────── │
│ [🔄 Maintenance] 유지 모드       │
│ [📦 Archive] 보관               │
│                                 │
└─────────────────────────────────┘
```

**MVP 상태 (4개)**:
| 상태 | 아이콘 | 설명 | 스트릭 |
|------|--------|------|--------|
| Active | 🟢 | 진행 중 | 카운트 |
| Paused | ⏸️ | 일시 중지 | 유지 |
| Backlog | 📋 | 나중에 | 미표시 |
| Completed | ✅ | 달성 완료 | 고정 |

**Phase 2 추가 상태 (2개)**:
| 상태 | 아이콘 | 설명 |
|------|--------|------|
| Maintenance | 🔄 | 유지 모드 (반복) |
| Archive | 📦 | 보관 (숨김) |

**Phase 2: 카드 스와이프 빠른 변경**

- Goal 카드 좌로 스와이프 → Backlog
- Goal 카드 우로 스와이프 → Paused

## 6. 사용자 시나리오

### 시나리오: 새 Goal 추가

1. 로드맵 화면에서 [+] 버튼 탭
2. "새 목표" 선택
3. Area 선택: "커리어"
4. Goal 이름 입력: "영어 면접 가능 수준"
5. Why 입력: "해외 취업을 준비하고 있어서"
6. (선택) Phase 추가 또는 바로 Task 추가
7. 저장 → 커리어 영역에 새 Goal 표시
