# Profile (프로필/설정) Wireframe

## 개요

프로필은 **상단 바에서 접근**하는 메뉴/설정 화면입니다.

- 모바일: 햄버거 메뉴 [≡] → 슬라이드 패널
- 데스크톱: 프로필 아이콘 [👤] → 드롭다운 메뉴

## 섹션별 상세

### 1. 슬라이드 패널 (모바일)

- 요소: 프로필 영역, 메뉴 리스트, 하단 정보
- 크기: 너비 280px, 전체 높이
- 애니메이션: 좌측에서 슬라이드 인 (300ms)
- 배경: 기존 화면 50% 어둡게

### 2. 드롭다운 메뉴 (데스크톱)

- 요소: 사용자 이름, 메뉴 아이템 (설정, 통계, 로그아웃)
- 크기: 너비 160px, 패딩 12px
- 스타일: border-radius 12px, shadow
- 위치: 프로필 아이콘 아래 정렬

### 3. 프로필 영역 (슬라이드 패널)

- 요소: 프로필 사진 (60x60px), 이름, 이메일
- 크기: 높이 100px, 패딩 20px
- 스타일: 프로필 사진 border-radius 30px

### 4. 메뉴 아이템

- 요소: 아이콘 (20x20px), 텍스트, 화살표 (선택)
- 크기: 행 높이 48px, 패딩 16px
- 스타일: 탭 시 배경색 Gray 50

### 5. 설정 카드

- 요소: 아이콘, 타이틀, 서브타이틀, 화살표/토글
- 크기: 높이 64px, 패딩 16px, 간격 8px
- 스타일: border-radius 12px, 배경 white

## 인터랙션

### 탭/클릭

| 요소                          | 동작                       |
| ----------------------------- | -------------------------- |
| [≡] 햄버거 (모바일)           | 슬라이드 패널 열기         |
| [👤] 프로필 아이콘 (데스크톱) | 드롭다운 메뉴 토글         |
| 패널/드롭다운 외부 영역       | 닫기                       |
| 메뉴 아이템                   | 해당 화면으로 이동         |
| 설정 카드 (화살표)            | 상세 설정 화면으로 이동    |
| 테마 토글                     | 라이트/다크 모드 즉시 전환 |
| 로그아웃                      | 로그아웃 확인 다이얼로그   |
| [<] 뒤로가기                  | 이전 화면으로 복귀         |

### 스와이프

| 방향                 | 동작      |
| -------------------- | --------- |
| 슬라이드 패널 좌측   | 패널 닫기 |
| 설정 화면 우측 (iOS) | 뒤로가기  |

### 스크롤

| 영역          | 동작                     |
| ------------- | ------------------------ |
| 슬라이드 패널 | 메뉴 많을 시 세로 스크롤 |
| 설정 화면     | 세로 스크롤              |

## 접근 방법

| 플랫폼   | 접근                                                       |
| -------- | ---------------------------------------------------------- |
| 모바일   | 상단 바 [≡] 탭 → 슬라이드 패널 → 메뉴 선택                 |
| 데스크톱 | 상단 바 [👤] 클릭 → 드롭다운 → "설정" 또는 사이드바 "설정" |
