# Inbox (인박스) Wireframe

## 개요

인박스는 **상단 바에서 접근**하는 오버레이/바텀시트 화면입니다.

- 모바일: 바텀시트 (화면 80% 높이)
- 데스크톱: 우측 패널 또는 중앙 모달

## 섹션별 상세

### 1. 헤더

- 요소: 📥 아이콘, "인박스" + 미정리 수 배지, [+] 추가 버튼
- 크기: 높이 48px, 패딩 16px
- 닫기: 핸들 드래그 다운 (모바일), [X] 버튼 (데스크톱)

### 2. 인박스 아이템 카드

- 요소: 메모 내용, 등록 날짜, 액션 버튼 3개
- 크기: 카드 높이 80px+, padding 16px, 간격 12px
- 스타일: 배경 white, border-radius 12px, shadow
- 액션 버튼:
  - 🔗 연결: 로드맵 Goal/Task에 연결
  - 📌 일상: 일상 영역으로 이동
  - 🗑️ 삭제: 삭제 확인 후 삭제

### 3. 보관함 섹션

- 요소: "보관함 (n)" 라벨, 펼침/접힘 화살표
- 크기: 높이 48px
- 기본: 접힌 상태
- 동작: 탭 시 보관된 아이템 표시

## 인터랙션

### 탭/클릭

| 요소          | 동작                    |
| ------------- | ----------------------- |
| [+] 버튼      | 빠른 캡처 입력창 표시   |
| 카드 영역     | 아이템 상세/편집        |
| [🔗 연결]     | 로드맵 연결 바텀시트    |
| [📌 일상]     | 일상 영역 이동 확인     |
| [🗑️ 삭제]     | 삭제 확인 다이얼로그    |
| 보관함        | 보관된 아이템 펼침/접힘 |
| 핸들 (모바일) | 드래그로 닫기           |
| 배경 영역     | 바텀시트/패널 닫기      |

### 스와이프

| 방향      | 동작           |
| --------- | -------------- |
| 카드 좌측 | 삭제 버튼 노출 |
| 카드 우측 | 보관 버튼 노출 |
| 핸들 하단 | 바텀시트 닫기  |

### 스크롤

| 영역        | 동작                   |
| ----------- | ---------------------- |
| 리스트 영역 | 세로 스크롤, 헤더 고정 |
