# Search (검색) Wireframe

## 개요

검색은 **상단 바에서 접근**하는 오버레이/드롭다운 화면입니다.

- 모바일: 전체 화면 오버레이
- 데스크톱: 드롭다운 오버레이 (중앙 모달 스타일)

## 섹션별 상세

### 1. 검색바

- 요소: 🔍 아이콘, 입력 필드, [X]/[ESC] 닫기 버튼
- 크기: 높이 52px, 패딩 16px
- 자동 포커스: 오버레이 열리면 즉시 키보드 표시
- 단축키 (데스크톱): `Cmd/Ctrl + K`

### 2. 최근 검색어

- 요소: 섹션 라벨, 검색어 칩 (가로 스크롤), 삭제 버튼
- 크기: 칩 높이 32px, 간격 8px, border-radius 16px
- 동작: 칩 탭 시 해당 검색어로 즉시 검색

### 3. 필터 탭

- 요소: 전체\*, 목표, 실천, 기록
- 크기: 높이 44px, 패딩 12px
- 스타일: 활성 탭 = Primary 색상 + 밑줄
- 기본: "전체" 선택

### 4. 검색 결과

- 요소: 결과 카운트, 결과 카드 리스트
- 카드 구성:
  - 아이콘: 🎯 (Goal), ✓ (Task), 📝 (기록), 📥 (인박스)
  - 제목: 검색 키워드 **볼드** 처리
  - 경로/날짜: 부가 정보
- 크기: 카드 높이 64px, 간격 8px, 패딩 12px 16px

## 인터랙션

### 탭/클릭

| 요소                 | 동작                                  |
| -------------------- | ------------------------------------- |
| 상단 바 🔍 아이콘    | 검색 오버레이 열기                    |
| 검색바               | 키보드 표시, 포커스                   |
| 최근 검색어 칩       | 해당 검색어로 즉시 검색               |
| [삭제] 버튼          | 최근 검색어 전체 삭제                 |
| 필터 탭              | 해당 유형만 필터링                    |
| 결과 카드            | 해당 항목 상세로 이동 (오버레이 닫힘) |
| [X] / [ESC]          | 검색 오버레이 닫기                    |
| 배경 영역 (데스크톱) | 오버레이 닫기                         |

### 스와이프

| 방향         | 동작                    |
| ------------ | ----------------------- |
| 최근 검색어  | 가로 스와이프로 더 보기 |
| 개별 칩 좌측 | 해당 검색어 삭제        |

### 스크롤

| 영역        | 동작                          |
| ----------- | ----------------------------- |
| 결과 리스트 | 세로 스크롤, 검색바+필터 고정 |
| 무한 스크롤 | 결과 20개 초과 시 추가 로드   |

### 키보드 (데스크톱)

| 키           | 동작               |
| ------------ | ------------------ |
| Cmd/Ctrl + K | 검색 오버레이 열기 |
| ESC          | 오버레이 닫기      |
| ↑↓           | 결과 탐색          |
| Enter        | 선택된 결과로 이동 |
