# inu 철학, 핵심 가치 & 타겟 유저

> 내 인생의 로드맵을 그리고, 내 시간 안에서 목표와 실천을 관리하는 자기개발 서비스

---

## 한 줄 정의

**inu**는 인생 로드맵을 먼저 그리고, 내 시간 안에서 목표와 실천을 관리하는 자기개발 서비스

---

## inu의 철학

inu는 "계획대로 잘 될 때"만을 위한 앱이 아닙니다.

| 상황                           | inu의 응답               |
| ------------------------------ | ------------------------ |
| 목표가 바뀌어도 괜찮아요       | → Goal 진화 시스템       |
| 쉬어야 할 때 쉬어도 괜찮아요   | → 의식적 휴식            |
| 모든 걸 다 못해도 괜찮아요     | → 영역 트레이드오프 인식 |
| 방향을 모르겠어도 괜찮아요     | → Direction 탐색 모드    |
| 삶에 큰 변화가 생겨도 괜찮아요 | → 인생 재정비 모드       |

**삶은 예측대로 흘러가지 않습니다.**
inu는 그 불확실성 속에서도 함께하는 동반자입니다.

---

## 연구 기반 설계 원칙

| 원칙                    | 근거                                                                   |
| ----------------------- | ---------------------------------------------------------------------- |
| **목표 조정은 적응적**  | Wrosch et al. (2003): 목표 조정 능력이 웰빙과 건강에 긍정적            |
| **자율적 선택이 중요**  | Self-Determination Theory: 스스로 선택한 변화가 강제된 변화보다 적응적 |
| **휴식은 성과의 일부**  | APA 연구: 주기적 회복이 장기 번아웃 방지                               |
| **트레이드오프는 현실** | Conflict Model: 삶의 영역들은 제한된 자원을 두고 경쟁                  |
| **20-30대는 탐색기**    | Arnett (2000): Emerging Adulthood의 핵심 특징은 정체성 탐색            |

## 핵심 가치

| 가치                 | 설명                                                                                                  |
| -------------------- | ----------------------------------------------------------------------------------------------------- |
| **인생 로드맵**      | 내 인생의 전체 로드맵이 먼저 있고, 그 안에서 목표와 할 일이 존재 — "왜 이걸 하는지" 맥락이 항상 보임  |
| **모든 레벨의 Why**  | Area, Goal, Phase, Task 각각에 "왜?"를 부여 — 아래에서 위로 올라가면 내 인생의 근본적인 이유가 드러남 |
| **시간 속의 실천**   | 내 실제 일정 안에서 Task가 배치됨. Google Calendar와 연동되어 "지금 뭘 할 차례인지" 바로 보임         |
| **로드맵 안의 기록** | 회고와 기록이 로드맵에 연결 — 왜 멈췄는지, 뭘 배웠는지 쌓이면 다음 도전에서 AI가 과거를 참고해 도움   |
| **최소 마찰**        | 매일 10초면 체크인 완료, 부담 제로. 스트릭이 끊겨도 누적은 남음                                       |
| **현실적 조언**      | AI 어드바이저가 데이터 + 과거 기록을 보고 페이스 조절, 목표 분해, 시간 배치 도움                      |

## 해결하고자 하는 문제

사람들은 목표가 있지만 잘 달성하지 못합니다. 그 이유는 대부분 이 5가지에 해당합니다:

| 문제                   | 현실                                        | inu의 해결 방식                                                 |
| ---------------------- | ------------------------------------------- | --------------------------------------------------------------- |
| **왜 하는지 모름**     | 목표만 세우고 동기가 흐릿해짐               | 모든 목표에 "왜?"를 연결하는 Why Chain                          |
| **정리가 안 됨**       | 하고 싶은 건 많은데 머릿속에서만 맴돌음     | 인생 영역별로 하고 싶은 것을 전부 펼쳐놓고, 지금 할 것만 활성화 |
| **비현실적 목표**      | 너무 큰 목표 → 실패 → 자책 반복             | AI가 현재 상태를 보고 현실적 페이스 조정 제안                   |
| **꾸준함 부족**        | 며칠 하다 흐지부지                          | 원탭 체크인 + 스트릭 + 새 라운드 철학으로 부담 없이 매일 유지   |
| **시간이 없다고 느낌** | 일정과 실천이 따로 놀아서 빈 시간을 못 찾음 | 캘린더에 Task와 일정이 함께 보여서 빈 시간 활용                 |

---

## 핵심 컨셉 5가지 요약

| 컨셉              | 설명                                                                     |
| ----------------- | ------------------------------------------------------------------------ |
| **Life Roadmap**  | Direction → Area → Goal → Phase → Task 5단계 구조. 내 인생 전체가 한눈에 |
| **Why Chain**     | 모든 레벨에 "왜?"를 부여. Task에서 위로 올라가면 인생의 근본 이유가 보임 |
| **원탭 체크인**   | Done/Skip 원탭으로 15초 완료. 새 라운드 철학으로 부담 없이               |
| **캘린더 통합**   | 시간대별 Task 배치 + Google Calendar 연동. "지금 뭘 할 차례인지" 명확    |
| **AI 어드바이저** | 과거 기록을 참고해 개인화된 조언. 목표 분해, 페이스 조절, 동기 부여      |

---

## 타겟 유저

### 주 타겟

**"목표는 있는데 실천이 안 되는 20~30대"**

- 자기개발에 관심이 많고 노션/메모 등에 목표를 적어본 경험이 있음
- 하고 싶은 것이 많아서 뭐부터 해야 할지 모름
- 습관 앱을 써봤지만 단순 체크리스트에 질림
- 왜 이 목표를 해야 하는지, 큰 그림을 보고 싶음

---

## 유저 페르소나

### 지은 (27세, 직장인)

> "올해 목표를 10개나 세웠는데 2월이면 다 잊어버려요.
> 목표가 너무 많아서 뭐부터 해야 할지 모르겠고,
> 하다 보면 '이걸 왜 하고 있지?' 싶을 때가 있어요."

| 구분          | 내용                                                    |
| ------------- | ------------------------------------------------------- |
| **원하는 것** | 목표를 정리하고, 매일 조금씩 해나가는 느낌              |
| **싫은 것**   | 복잡한 앱, 매일 길게 기록하는 것, 못하면 죄책감 주는 것 |

### 민수 (31세, 프리랜서)

> "운동, 영어, 사이드 프로젝트... 다 하고 싶은데
> 현실적으로 뭘 먼저 해야 할지 누가 좀 알려줬으면 좋겠어요."

| 구분          | 내용                                                     |
| ------------- | -------------------------------------------------------- |
| **원하는 것** | 현재 상태를 보고 뭘 하면 좋을지 조언해주는 것            |
| **싫은 것**   | 스스로 우선순위 정하는 것, 계획 세우는 데만 시간 쓰는 것 |
