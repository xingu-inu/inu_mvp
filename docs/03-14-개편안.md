# 03-14 App Structure Overhaul: Roadmap-First 2-Tab Transition

## Background

inu's core value is the **Roadmap** — mapping out the big picture of your life and receiving AI coaching in each area (fitness, career, learning, etc.) to fine-tune your direction. The current 3-tab structure (Home / Roadmap / Review) dilutes this core value because the calendar-centric "Home" tab takes center stage.

### Current Problems

- Home (Calendar) is the first tab → app looks like a generic calendar app
- Roadmap is the second tab → core value feels secondary
- The calendar grid (24-hour Google Calendar style) is excessively heavy

### Vision

- Personalized AI coach conversations per Roadmap Area (e.g., fitness trainer, career mentor)
- Section-specific service/app recommendations
- The essence of the service: mapping out and executing your life's big picture

---

## Decisions

### Tab Structure: 3 Tabs → 2 Tabs

| Before                  | After                |
| ----------------------- | -------------------- |
| Home · Roadmap · Review | **Roadmap · Review** |

- Remove Home (Calendar) tab
- Roadmap becomes the first tab = the face of the app
- Default landing page: `/roadmap`

### Daily Check-in: Integrated into Roadmap Right Panel

To maintain a daily reason to open the app even without the calendar, the **roadmap right panel's default state shows "Today's Tasks"**.

```
No goal selected (default):     Goal selected:
┌─────────────────────┐        ┌─────────────────────┐
│ Mar 14 (Fri)  ◀ ▶   │        │ ← Goal Detail        │
│─────────────────────│        │  (existing)          │
│ [Health] Morning    ✅│        │ GoalBrowsePanel      │
│ [Career] Code Review⬜│        │ (no changes)         │
│ [Learning] English  ⬜│        │                      │
│─────────────────────│        │                      │
│ 💭 Today's reflection │        │                      │
└─────────────────────┘        └─────────────────────┘
```

- No goal selected → "Today's Tasks" (grouped by Area/Goal, with check-in)
- Goal clicked → existing GoalBrowsePanel (no changes)
- Includes check-in (done/skip) + simple daily reflection input

### Calendar Restoration Path

- Home-related code is **NOT deleted** (can be restored later via settings toggle)
- Check-in DB/API/services remain intact
- `/home` URL access redirects to `/roadmap` (handles existing bookmarks/links)
- Future: "Calendar" option in settings adds "Today" tab back (3-tab restoration)

---

## Analysis

### Risks of Settings Toggle Approach (Rejected)

1. **Core loop collapse** — Removing check-in from `Onboarding → Roadmap → Check-in → Streak → Review` breaks the entire loop
2. **DAU drop** — Roadmap is a planning tool used 1-2x/week. Daily check-in drives daily opens
3. **Empty screen problem** — Need to design what shows when calendar is toggled off

### Advantages of Chosen Approach

1. **Roadmap as the app's face** — First tab = core value is clear
2. **Daily touchpoint preserved** — Today's tasks + check-in available in right panel
3. **Contextual connection** — Check-in lives inside Roadmap, feels like "today's execution of my life's big picture"
4. **Clean UI** — 2 tabs, simple and focused
5. **AI coaching extensible** — Future coaching buttons per Area section fit naturally
