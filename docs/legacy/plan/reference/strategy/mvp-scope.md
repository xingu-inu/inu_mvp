# MVP 범위

> 핵심 루프에 집중한 최소 기능 범위

---

## MVP 핵심 루프

```
온보딩 → 로드맵 만들기 → 매일 체크인 → 스트릭 쌓기 → 진행률 보기
```

---

## MVP 포함 기능

### 페이지

| 페이지       | MVP 범위                                                           |
| ------------ | ------------------------------------------------------------------ |
| Landing/Auth | 이메일 가입/로그인, Google 소셜 로그인                             |
| Onboarding   | 가치 칩 선택, Direction 생성/수정, 탐색 모드                       |
| Today        | 시간대별 그룹핑, 체크인 카드, Done/Skip, 기분 선택, AI 한마디      |
| Roadmap      | 트리 뷰, 카드 뷰, Active/Backlog 필터, Phase 인디케이터, Goal 상세 |
| Calendar     | 주간 뷰, 월간 뷰, Action Panel (기본 리스트, 티어 없음)            |
| Review       | 주간 달성률, 스트릭 현황, 저널 타임라인                            |
| Profile      | 기본 설정, Direction 변경                                          |
| Inbox        | 빠른 캡처, 로드맵 연결, 삭제                                       |
| Search       | 통합 검색, 기본 필터                                               |

### 기능

| 기능            | MVP 범위                                              |
| --------------- | ----------------------------------------------------- |
| Life Roadmap    | 5단계 구조, Active/Backlog, Phase 시스템              |
| Why Chain       | Direction 필수, 나머지 Why 선택, Task 카드에 Why 표시 |
| 체크인 & 스트릭 | Done/Skip/Miss, 스트릭 카운터, 새 라운드 철학         |
| AI 어드바이저   | 규칙 기반 메시지 (스트릭, 완료 축하 등 즉시 표시)     |
| 여정 기록       | 데일리/마일스톤 자동 기록, 타임라인 뷰                |
| Goal 생명주기   | Active/Backlog/Completed 상태                         |
| 시간 관리       | 시간대 그룹핑 (5+1)                                   |

## Phase 2 (확장)

| 기능                 | 내용                                                   |
| -------------------- | ------------------------------------------------------ |
| **AI 허브 페이지**   | AI 전용 페이지 (자유 대화, TODO 제안, 타임라인 최적화) |
| AI 대화 버튼         | Roadmap/Calendar/Review에서 AI 호출 버튼               |
| AI TODO 제안         | 패턴 기반 다음 할 일 추천                              |
| AI 타임라인 최적화   | Task 시간대 재배치 제안                                |
| 규칙 기반 확장       | Goal 정체 알림, 빈 시간 표시, 영역 불균형              |
| Google Calendar 연동 | 읽기, 충돌 감지                                        |
| 캘린더 드래그 배치   | Action Panel에서 드래그                                |
| Action Panel 3티어   | 🔥핵심/⭐중요/📌기타 분류                              |
| 보드(칸반) 뷰        | Area별 컬럼 드래그                                     |
| 비전 모드            | Goal을 완료 비전 문장으로 표시                         |
| WOOP 설정            | 장애물 + if-then 계획                                  |
| Why 온도 체크        | Goal별 동기 유효성 확인                                |
| 자유 기록 작성       | 저널에 직접 기록                                       |
| 일상 영역            | 로드맵 외 잡무 관리                                    |
| 월간 리뷰            | 추이 그래프, 영역 균형 레이더                          |
| 성장 궤적            | Phase 진행 시각화                                      |
| 인생 재정비 모드     | 기본 플로우                                            |

## Phase 3+ (미래)

| 기능               | 내용                         |
| ------------------ | ---------------------------- |
| AI 자유 대화       | 목표/삶에 대해 자유롭게 대화 |
| 고급 AI 분석       | 패턴 분석, 개인화 코칭       |

| 소셜 기능          | 친구 초대, 응원 보내기       |
| 위젯               | 홈 화면 위젯                 |
| 오프라인 모드      | 인터넷 없이 기본 기능        |
