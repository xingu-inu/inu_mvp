# Life Roadmap 시스템

> 내 인생의 로드맵이 먼저 있고, 그 안에서 목표와 할 일이 존재합니다.

---

## 1. 개요

Life Roadmap은 inu의 핵심 시스템입니다. 단순한 할 일 관리가 아니라, **나의 방향(Direction)**을 최상위에 두고, 인생에서 중요한 영역을 펼쳐놓고, 각각에 "왜 중요한지"를 붙이고, 큰 목표를 단계(Phase)로 나누고, 그 안에서 실천이 자연스럽게 연결되는 구조입니다.

## 3. 5단계 구조

```
Direction (방향)
    ↓
Area (영역)
    ↓
Goal (목표)
    ↓
Phase (단계) — 선택적
    ↓
Task (실천)
```

### 각 레벨의 역할

| 레벨 | 이름      | 성격                    | 예시                                               |
| ---- | --------- | ----------------------- | -------------------------------------------------- |
| -1   | Direction | 인생의 방향, Why의 근원 | "건강하고 성장하는 삶을 통해 가족과 오래 행복하게" |
| 0    | Area      | 인생에서 중요한 영역    | 건강, 커리어, 재정, 관계, 취미                     |
| 1    | Goal      | 구체적 달성 목표        | "10km 달리기", "영어 면접 가능"                    |
| 1.5  | Phase     | 중간 이정표 (선택적)    | "기초 체력 만들기", "5km 안정화"                   |
| 2    | Task      | 반복 행동, 체크인 대상  | "매일 30분 러닝"                                   |

---

## 4. Phase 시스템

큰 목표를 단계로 나누고, "지금 여기"를 보여줍니다.

### 규칙

- Goal 안에 **선택적으로** Phase를 둘 수 있음
- Phase가 있는 Goal: **현재 활성 Phase의 Task만** 오늘 화면에 표시
- Phase 완료 → 다음 Phase 활성화

### Phase 인디케이터

```
Phase 1 ●━━ Phase 2 ○━━ Phase 3 ○
```

### Phase 완료 시 이전 습관 처리

| 선택지                  | 설명                                       |
| ----------------------- | ------------------------------------------ |
| 🔄 유지하며 계속 (추천) | 이전 Phase 습관을 유지하면서 새 Phase 시작 |
| ⏸️ 잠시 멈추기          | 이전 Phase 습관을 일시 정지                |
| ✅ 완전히 졸업          | 이전 Phase 습관을 완료 처리                |

## 5. Active vs Backlog

**모든 것을 리스트에 넣되, 지금 할 것만 켠다.**

| 상태            | 의미                      | Today 화면        |
| --------------- | ------------------------- | ----------------- |
| **Active**      | 지금 실제로 하는 목표     | Task가 표시됨     |
| **Backlog**     | 하고 싶지만 아직 안 한 것 | 표시 안 됨        |
| **Completed**   | 달성 완료                 | 기록으로 남음     |
| **Maintenance** | 달성 후 유지 모드         | 유지 Habit만 표시 |
| **Paused**      | 잠시 멈춤                 | 표시 안 됨        |

---

## 6. 이 구조가 주는 가치

1. **"내 인생 전체"가 한눈에 보인다** — Area별로 뭘 원하는지, 어디에 투자하는지
2. **"지금 어디, 다음은 뭔지" 보인다** — Phase가 현재 위치를 알려줌
3. **새로운 게 생기면 바로 연결** — Backlog로 추가 → 나중에 Active로 전환
4. **과부하가 보인다** — 커리어에 Active가 3개인데 건강은 0개? → AI가 밸런스 체크 제안
5. **버리지 않아도 된다** — 일단 다 Backlog에 넣어두면 됨
6. **우선순위가 자연스럽게** — Active로 켜는 행위 자체가 선언
7. **시간이 구체적** — Task에 시간대가 있어서 "언제 할지"까지 보임
