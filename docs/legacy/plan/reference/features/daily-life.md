# 인박스 & 일상 영역

> 빠른 캡처, 로드맵 밖의 할 일 관리

---

## 1. 개요

인박스와 일상 영역은 **서로 다른 목적**을 가집니다:

| 구분     | 인박스 (Inbox)                 | 일상 영역 (Daily Life)  |
| -------- | ------------------------------ | ----------------------- |
| **목적** | 임시 저장소 (정리 전)          | 로드맵 외 반복 할 일    |
| **성격** | 휘발성, 정리 필요              | 지속성, 루틴            |
| **예시** | "나중에 읽을 기사", "아이디어" | "장보기", "공과금 납부" |
| **MVP**  | ✅ 포함                        | Phase 2                 |

> **MVP 단순화**: MVP에서는 인박스만 제공합니다.
> 일상 영역(로드맵 밖 잡무)은 Phase 2에서 추가됩니다.
> MVP에서 "장보기" 같은 일상 할 일은 Inbox에 임시로 넣거나, "일상" Area를 만들어 관리할 수 있습니다.

## 3. 인박스 기능

### 3초 캡처

어디서든 빠르게 아이디어/할 일 캡처:

- 상단 바 📥 탭
- 플로팅 버튼 [+] → 빠른 메모

### 인박스 아이템 액션

| 액션             | 설명                           |
| ---------------- | ------------------------------ |
| 🔗 로드맵 연결   | Goal/Phase에 Task로 연결       |
| 📋 일상으로 이동 | 로드맵 외 "일상 영역"으로 이동 |
| 📦 보관          | 나중을 위해 보관               |
| 🗑 삭제          | 삭제                           |

---

## 4. 일상 영역

로드맵 Goal에 속하지 않는 일상적인 할 일:

- 장보기
- 병원 예약
- 공과금 납부
- 등등

### Today 화면에서

```
── 🕐 일상 ──────────────────
📋 장보기
📋 병원 예약
```

- 로드맵 Task와 구분되어 표시
- 체크인 가능 (스트릭 없음)
