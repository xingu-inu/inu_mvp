# 체크인 & 스트릭 시스템

> Done/Skip 원탭으로 15초 완료. 새 라운드 철학으로 부담 없이.

---

## 1. 개요

매일 앱을 열면 오늘 할 Task 목록이 시간대별로 카드로 나열됩니다. 각 카드에 **Done / Skip** 두 버튼만 있어서 10초면 체크인 완료.

## 3. 핵심 원칙

| 원칙               | 설명                                                  |
| ------------------ | ----------------------------------------------------- |
| **최소 마찰**      | 탭 한 번으로 끝. 기록은 선택사항                      |
| **즉각 피드백**    | 탭하면 바로 색상 변화 + 스트릭 업데이트 + 파티클 효과 |
| **죄책감 없음**    | Skip은 "의도적 휴식"으로 스트릭이 깨지지 않음         |
| **새 라운드 철학** | 스트릭이 끊겨도 누적 횟수는 영원히 남음               |

---

## 4. Done / Skip / Miss

| 액션     | 의미                    | 스트릭             | 누가        |
| -------- | ----------------------- | ------------------ | ----------- |
| **Done** | 했다!                   | +1                 | 사용자가 탭 |
| **Skip** | 오늘은 의도적으로 쉰다  | 유지 (깨지지 않음) | 사용자가 탭 |
| **Miss** | 자정까지 아무것도 안 함 | 새 라운드 시작     | 시스템 자동 |

> Skip과 Miss의 구분이 중요합니다. "의도적으로 쉬는 것"과 "그냥 까먹은 것"은 다릅니다.

---

## 5. 스트릭 철학: "새 라운드"

스트릭이 끊겨도 **0으로 돌아가지 않습니다**. 비디오 게임처럼 기록이 남습니다:

| 요소                  | 설명                              |
| --------------------- | --------------------------------- |
| **현재 스트릭**       | 이번 라운드의 연속 일수           |
| **이전 최고 기록 🏆** | 역대 최장 스트릭 (하이스코어)     |
| **누적 완료 횟수**    | 총 Done 횟수 (절대 리셋되지 않음) |

### 예시

```
🏃 매일 30분 걷기

스트릭: 3일 (새 라운드)
이전 최고: 15일 🏆
누적: 47회

→ 스트릭 끊겨도 47회는 절대 사라지지 않음
```

## 6. 체크인 카드 구성

```
┌─────────────────────────────────┐
│ 🏃 매일 30분 걷기  🟢🔥12 30분 │
│ └ 기초 체력(Phase1) · 💪 건강   │
│ 💭 "유산소가 기초 체력의 핵심"   │
│    [ ✅ Done ]   [ ⏭ Skip ]    │
└─────────────────────────────────┘
```

| 영역        | 내용                               |
| ----------- | ---------------------------------- |
| 좌상단      | 이모지 + Task 이름                 |
| 우상단      | Area 컬러 칩 + 🔥스트릭 + 소요시간 |
| 하위 텍스트 | Phase(있으면)·Goal · Area          |
| 💭 why      | Task의 why를 한 줄로 표시          |
| 하단 버튼   | Done / Skip                        |

## 9. Tiny Habits 연계 (선택적)

습관 Task 생성 시 Tiny Habits 원리를 안내:

```
💡 Tiny Habits 팁 (선택)

① 언제 할까요? 기존 루틴 뒤에 붙여보세요
   [양치 후] [커피 마실 때] [퇴근 후] [+ 직접]

② 최소 버전은? 2분이면 할 수 있는 크기로
   → "스트레칭 2분" (힘든 날은 이것만 해도 OK)
```

- 연속 미달성 시 "이 습관을 2분 버전으로 줄여볼까요?" AI 제안
