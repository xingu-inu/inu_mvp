## 3. PDCA 순환 구조

앱의 4개 탭이 PDCA 순환을 반영합니다:

| 탭        | PDCA            | 역할             |
| --------- | --------------- | ---------------- |
| 🗺 로드맵 | **Plan (What)** | 무엇을 할지 계획 |
| 📅 캘린더 | **Plan (When)** | 언제 할지 계획   |

## 4. Goal 상태 전이

```
[생성] → Backlog → Active → Completed → (Maintenance or Archive)
                       ↓
                  Paused (일시 정지)
                       ↓
                  재시작 or 중단
```

### 상태 정의

| 상태            | 의미             | Today 표시   |
| --------------- | ---------------- | ------------ |
| **Active**      | 현재 진행 중     | Task 표시됨  |
| **Backlog**     | 나중에 시작 예정 | 표시 안 됨   |
| **Completed**   | 달성 완료        | 표시 안 됨   |
| **Maintenance** | 유지 모드        | 유지 Habit만 |
| **Paused**      | 일시 정지        | 표시 안 됨   |

## 5. Goal Cycling — 달성 후 순환

Goal을 달성했을 때, 단순히 "완료"가 아닌 **3가지 선택지**:

```
🎉 "10km 달리기" 목표 달성!

이 성취를 어떻게 이어갈까요?

[✅ 완료 & 아카이브]    → 이 목표는 끝. 기록으로 남김
[🔄 유지 모드로 전환]   → 달성 수준을 유지 (습관으로 전환)
[⬆️ 다음 레벨로]       → 하프마라톤처럼 새 사이클 시작
```

### 유지 모드 (Maintenance)

- Goal 상태가 "Maintenance"로 전환
- 진행률 100% + "유지 중" 배지
- 유지용 Habit만 활성화 (예: "주 3회 10km 러닝")
- 유지 스트릭 별도 카운트
- 로드맵에서 "안정된 녹색 링"으로 표시

### 다음 레벨

- 기존 Goal의 데이터/기록이 이어짐
- 새로운 Phase/Task 설정
- AI가 이전 달성 경험을 참고해 새 Phase 제안

## 6. Goal 진화 시스템

목표가 바뀌어도 괜찮습니다. inu는 목표 변화를 자연스럽게 받아들입니다.

### 변화 유형

| 유형          | 설명             | 처리 방식                       |
| ------------- | ---------------- | ------------------------------- |
| **방향 전환** | 목표 자체가 바뀜 | 중단 + 새 Goal 생성 (이력 연결) |
| **축소**      | 범위 줄이기      | Goal/Phase 수정                 |
| **확장**      | 범위 늘리기      | 새 Phase 추가                   |
| **일시 정지** | 잠시 멈춤        | Paused 상태 전환                |

### 중단 시 기록

```
🔄 "영어 공부" 방향을 전환합니다

왜 전환하게 되었나요? (선택)
[시간 부족] [흥미 감소] [우선순위 변경] [목표 재정의] [+ 직접]

이 경험에서 배운 것을 남겨두세요 (선택)
[___________________]

→ 나중에 다시 시작할 때 AI가 이 기록을 참고
```

---

## 7. Post-Reward Reset 방지

Goal 달성 직후 의욕 저하를 방지합니다:

- 달성 축하 후 바로 "다음은?" 대신 **"이 성취를 음미해보세요"**
- 1~3일 후 AI 카드: "이 경험으로 배운 것을 다음 도전에 활용해볼까요?"
