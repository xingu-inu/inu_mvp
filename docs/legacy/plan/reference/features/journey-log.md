# 여정 기록 시스템

> 체크인, 회고, 저널, 마일스톤, AI — 모든 기록이 하나의 타임라인으로.

---

## 1. 개요

inu는 사용자의 모든 활동을 "여정"으로 기록합니다. 체크인 완료, 회고, 자유 기록, 마일스톤, AI 조언이 시간순으로 쌓여 나만의 성장 스토리가 됩니다.

## 6. 데일리 회고 작성

Action 기반 회고 - 오늘 완료한 Task 중 선택하거나 "전체" 하루 회고

```
┌─────────────────────────────────┐
│ ✏️ 오늘의 회고                   │
│                                 │
│ 오늘 한 것:                      │
│ [●전체] [🏃러닝 ✓] [📖독서 ✓]   │
│                                 │
│ 기분: 😫 😕 😐 🙂 😄            │
│                                 │
│ 한줄: [_______________________] │
│                                 │
│              [저장]              │
└─────────────────────────────────┘
```

- **범위 선택**: "전체" (기본값) 또는 오늘 완료한 특정 Task
- **기분**: 5단계 이모지
- **한줄**: 짧은 회고 문장
- **진입점**: Today 화면 하단, 저녁 알림, Review 저널탭

### 데이터 연결

```
DailyReflection → Task → Phase → Goal → Area
```

Task 기반이라 Area별 분석도 자동으로 가능.

## 9. AI 활용

AI 어드바이저가 여정 기록을 참고:

- 비슷한 목표의 과거 시도 참조
- 패턴 분석 (기분 vs 달성률)
- 성장 궤적 분석
