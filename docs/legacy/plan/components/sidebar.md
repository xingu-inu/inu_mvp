# Sidebar (사이드바) 컴포넌트

> 데스크톱에서 사용되는 좌측 네비게이션 사이드바

---

## 개요

사이드바는 **데스크톱 화면(1024px+)에서만 표시**되는 주요 네비게이션 요소입니다.

- 메인 4개 탭 + 설정
- 모바일에서는 하단 탭 바로 대체

---

## 레이아웃

```
┌────────────────┐
│                │
│  * 홈          │ ← 현재 활성 탭
│    로드맵      │
│    캘린더      │
│    리뷰        │
│                │
│  ────────────  │ ← 구분선
│                │
│    설정        │
│                │
│                │
│                │
│                │
│                │
│                │
│  (200px)       │
└────────────────┘
높이: 전체 화면 - 상단 바 높이
```

---

## 요소별 상세

### 1. 메인 네비게이션

| 순서 | 아이템 | 아이콘 | 화면     |
| ---- | ------ | ------ | -------- |
| 1    | 홈     | 🏠     | Home     |
| 2    | 로드맵 | 🗺️     | Roadmap  |
| 3    | 캘린더 | 📅     | Calendar |
| 4    | 리뷰   | 📊     | Review   |

### 2. 구분선

- 위치: 메인 네비게이션과 설정 사이
- 스타일: 1px solid Gray 200
- 마진: 상하 16px

### 3. 하단 메뉴

| 아이템 | 아이콘 | 화면     |
| ------ | ------ | -------- |
| 설정   | ⚙️     | Settings |

---

## 스타일

### 기본 스타일

```
사이드바:
- 너비: 200px
- 배경: white
- border-right: 1px solid Gray 100
- padding: 16px 0
- position: fixed
- height: calc(100vh - 56px)
- top: 56px (상단 바 높이)
```

### 메뉴 아이템

```
기본 상태:
- height: 44px
- padding: 12px 16px
- font-size: 15px
- font-weight: Medium (500)
- color: Gray 700
- border-radius: 8px (좌우 마진 8px 내)

호버 상태:
- background: Gray 50

활성 상태:
- background: Primary 50
- color: Primary 600
- font-weight: SemiBold (600)
- border-left: 4px solid Primary 600
- padding-left: 12px (4px 줄어듦)
```

```
┌────────────────┐
```

## 반응형

| 화면 크기           | 사이드바     | 대체 요소  |
| ------------------- | ------------ | ---------- |
| Mobile (<768px)     | 숨김         | 하단 탭 바 |
| Tablet (768-1023px) | 숨김         | 하단 탭 바 |
| Desktop (≥1024px)   | 표시 (200px) | -          |
| Wide (≥1440px)      | 표시 (240px) | -          |

## 아이템 명칭 규칙

| -------- | ------------- |
| Home     | 홈            |
| Roadmap  | 로드맵        |
| Calendar | 캘린더        |
| Review   | 리뷰          |
| Settings | 설정          |

---

## 인터랙션

### 클릭

| 요소             | 동작                     |
| ---------------- | ------------------------ |
| 메인 메뉴 아이템 | 해당 화면으로 네비게이션 |
| 설정             | 설정 화면으로 이동       |

### 키보드

| 키    | 동작                |
| ----- | ------------------- |
| ↑↓    | 메뉴 아이템 간 이동 |
| Enter | 선택된 메뉴로 이동  |

---

## 접근성

- 모든 메뉴에 aria-label 제공
- 현재 페이지 aria-current="page"
- 키보드 네비게이션 완전 지원
- 포커스 표시 명확히
