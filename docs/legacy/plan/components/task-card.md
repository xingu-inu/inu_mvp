# Task 카드 컴포넌트

> 체크인 카드, 로드맵 Task 등에서 재사용되는 핵심 컴포넌트

---

## 레이아웃

```
┌─────────────────────────────────┐
│ 🏃 매일 30분 걷기  🟢🔥12 30분 │
│ └ 기초 체력(Phase1) · 💪 건강   │
│ 💭 "유산소가 기초 체력의 핵심"   │
│    [ ✅ Done ]   [ ⏭ Skip ]    │
└─────────────────────────────────┘
```

---

## 구성 요소

| 영역        | 내용                             | 필수               |
| ----------- | -------------------------------- | ------------------ |
| 좌상단      | 이모지 + Task 이름               | Y                  |
| 우상단      | Area 컬러 칩 + 스트릭 + 소요시간 | 스트릭 Y, 나머지 N |
| 서브 텍스트 | Phase·Goal·Area 경로             | N                  |
| Why 행      | 💭 Task.why                      | N                  |
| 액션        | Done/Skip 버튼 (Today만)         | Today만            |

---

## 상태별 스타일

| 상태   | 배경색      | 표시 | 설명                    |
| ------ | ----------- | ---- | ----------------------- |
| 미완료 | 기본 (흰색) | -    | 아직 체크인하지 않음    |
| Done   | 초록 배경   | ✅   | 완료됨                  |
| Skip   | 회색 배경   | ⏭   | 건너뜀 (새 라운드 시작) |
| Miss   | 연한 빨강   | -    | 자동 미완료 처리됨      |

---

## 인터랙션

### 탭 (기본)

- 카드 탭 → 확장하여 상세 정보 표시
- Goal 상세로 이동하는 링크

### Done/Skip 버튼

- 원탭으로 15초 내 체크인 완료 목표
- Done → 초록색 전환 + 파티클 애니메이션
- Skip → "다음 라운드에서 함께해요" 메시지

### 확장 시 추가 정보

- 연결된 Goal/Phase 경로
- Why Chain 전체
- 최근 완료 히스토리

## 사용 화면

| 화면     | 용도      | Done/Skip 버튼 |
| -------- | --------- | -------------- |
| Today    | 체크인    | ✅ 있음        |
| Roadmap  | Task 목록 | ❌ 없음        |
| Calendar | 시간 배치 | ❌ 없음        |
