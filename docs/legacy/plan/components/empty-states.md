# 빈 상태 UX (Empty State)

> 빈 상태에서 다음 행동을 자연스럽게 유도

---

## 원칙

- 빈 상태 ≠ 에러 → **부드럽고 가이드하는 톤**
- 항상 **다음 행동 유도** (CTA 버튼)
- 일러스트/아이콘으로 시각적 따뜻함
- "아직"이라는 표현 → 앞으로 채워질 거라는 기대감

---

## 화면별 빈 상태

### Today (할 일 0개)

```
┌─────────────────────────────────┐
│                                 │
│            🌟                   │
│                                 │
│     오늘은 아직 비어있어요       │
│                                 │
│   [목표에서 가져오기]  [빠르게 추가]│
│                                 │
└─────────────────────────────────┘
```

### Roadmap (목표 0개)

```
┌─────────────────────────────────┐
│                                 │
│            🗺️                   │
│                                 │
│     로드맵을 채워볼까요?         │
│                                 │
│     [목표 추가]  [예시 보기]     │
│                                 │
└─────────────────────────────────┘
```

### Inbox (0개)

```
┌─────────────────────────────────┐
│                                 │
│            ✨                   │
│                                 │
│     인박스가 깨끗해요!           │
│                                 │
│     (CTA 불필요 - 비움 = 긍정)  │
│                                 │
└─────────────────────────────────┘
```

### 저널 (기록 0개)

```
┌─────────────────────────────────┐
│                                 │
│            📖                   │
│                                 │
│     아직 여정 기록이 없어요      │
│                                 │
│     데일리에서 한 줄 남겨보세요  │
│                                 │
└─────────────────────────────────┘
```

### 검색 결과 없음

```
┌─────────────────────────────────┐
│                                 │
│            🔍                   │
│                                 │
│     검색 결과가 없어요          │
│                                 │
│         [다시 검색]             │
│                                 │
└─────────────────────────────────┘
```

```
└─────────────────────────────────┘
```

## 컴포넌트 구조

```jsx
<EmptyState>
  <Icon />
  <Message>메시지</Message>
  <Actions>
    <Button primary>주요 CTA</Button>
    <Button secondary>보조 CTA</Button>
  </Actions>
</EmptyState>
```
