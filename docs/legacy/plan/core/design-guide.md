# UI/UX 디자인 가이드

---

## 디자인 원칙

| 원칙                       | 설명                                  | 적용                                                   |
| -------------------------- | ------------------------------------- | ------------------------------------------------------ |
| **최소 마찰**              | 매일 하는 행동은 탭 1번으로 끝나야 함 | 체크인 원탭, 기분 원탭                                 |
| **즉각 피드백**            | 행동에 대한 반응이 즉시 보여야 함     | 색상 변화, 스트릭 애니메이션                           |
| **죄책감 없음**            | 못 해도 비난하지 않음                 | Skip 허용, 새 라운드 철학, 부드러운 Miss 표현, AI 공감 |
| **시간 인식**              | 내 시간 속에서 실천이 배치됨          | 시간대별 그룹핑, 캘린더 통합 뷰, 빈 시간 제안          |
| **Progressive Disclosure** | 기본은 심플, 상세는 필요할 때만       | 수치 입력 선택적, Phase 선택적, 시간 설정 선택적       |
| **맥락 제공**              | 왜 이걸 하고 있는지 항상 보임         | 체크인 카드에 Phase/Goal/Area + Task.why, Why Chain    |
| **단계적 성취**            | 큰 목표를 작은 이정표로 나눔          | Phase 시스템, Phase 완료 축하, 마일스톤 회고           |
| **데이터 기반 조언**       | 감이 아니라 실제 데이터로             | AI가 달성률/스트릭/기분/시간 패턴 참고                 |

## 톤 & 보이스

- **친근하지만 가볍지 않은** → "~요" 존댓말, 이모지 적절히 사용
- **격려하지만 현실적인** → 빈말 금지, 데이터에 근거한 칭찬
- **짧고 핵심만** → 긴 설교 없이, 한 메시지에 핵심 1~2개
- **비난 없음** → "왜 못했어요?" 대신 "혹시 이유가 있었나요?"

## 성장 마인드셋 — UX Writing 가이드

모든 부정적 상황에서 **성장 마인드셋 메시지**를 사용합니다:

| 상황        | 기존 표현 (X)              | 성장 마인드셋 (O)                                        |
| ----------- | -------------------------- | -------------------------------------------------------- |
| 스트릭 깨짐 | "스트릭이 끊겼습니다"      | "쉬는 것도 과정의 일부예요. 다시 시작하는 게 중요합니다" |
| 목표 미달성 | "목표를 달성하지 못했어요" | "아직 도달하지 못했어요. 무엇이 방해했을까요?"           |
| 목표 중단   | "포기"                     | "방향 전환. 이 경험에서 배운 것을 기록해두세요"          |
| 완료율 낮음 | "이번 주 30%밖에 못했어요" | "이번 주 30%를 해냈어요. 어떤 부분이 어려웠을까요?"      |
| 느린 진행   | "진행이 느려요"            | "자기 페이스를 지키고 있어요"                            |

**핵심**: 노력만 칭찬하지 않음 (거짓 성장 마인드셋 경고). "어떤 전략이 효과적이었나요?", "다르게 해볼 수 있는 방법은?" 질문으로 **전략 변화를 유도**.

## SDT(자기결정이론) 기반 설계 체크리스트

| SDT 요소   | 체크 포인트                                           |
| ---------- | ----------------------------------------------------- |
| **자율성** | 모든 AI 제안에 "내 방식대로" 옵션 존재하는가?         |
| **자율성** | 선택사항이 강제로 느껴지지 않는가? (건너뛰기 가능?)   |
| **유능감** | 작은 완료도 수치/시각적으로 인정받는가?               |
| **유능감** | 리뷰에서 "못한 것"보다 "한 것"이 먼저 보이는가?       |
| **관계성** | AI 톤이 "판단하는 코치"가 아닌 "이해하는 동행자"인가? |
| **관계성** | 소셜이 비교/경쟁이 아닌 응원/동행인가?                |

## 모바일 우선 반응형

- 기본 디자인은 모바일 (375px 기준)
- 태블릿/데스크톱에서는 여백이 넓어지고 카드가 그리드로 배치
- Bottom Nav는 모바일에서만 표시, 데스크톱에서는 좌측 사이드바로 전환
- 터치 타겟 최소 44px

## 터치 타겟 가이드

Apple HIG 기준을 따릅니다.

| 요소        | 최소 크기  | 권장 크기    |
| ----------- | ---------- | ------------ |
| 버튼        | 44px 높이  | 48-56px 높이 |
| 리스트 행   | 44px 높이  | 48px 높이    |
| 카드        | 56px+ 높이 | 64-80px 높이 |

```
✓ 올바른 예: 44px 이상 버튼 (편안한 터치)
```

## 구분선 대신 여백 사용

텍스트 구분선(----, ========)은 시각적 노이즈를 만듭니다.
**여백(White Space)으로 섹션을 구분**합니다.

```
❌ 잘못된 예:
┌─────────────────────┐
│ 섹션 A              │
│ ─────────────────── │ ← 구분선 노이즈
│ 섹션 B              │
└─────────────────────┘

✓ 올바른 예:
┌─────────────────────┐
│ 섹션 A              │
│                     │ ← 여백으로 구분 (16-24px)
│ 섹션 B              │
└─────────────────────┘
```

| 여백 크기 | 용도              |
| --------- | ----------------- |
| 8px       | 같은 그룹 내 요소 |
| 12px      | 관련 요소 간      |
| 16px      | 작은 섹션 구분    |
| 24px      | 주요 섹션 구분    |
| 32px      | 큰 영역 구분      |

```

- border-radius: 16px
- padding: 16px

- background: white
- 높이: 64-80px
```

```
스타일:
- border-radius: 20px
```

## 빈 상태 (Empty State) 가이드

빈 상태는 **기대감과 행동 유도**를 담아야 합니다.

### 템플릿

```
┌─────────────────────────────────────┐
│                                     │
│           [일러스트]                │ ← 부드러운 일러스트/이모지
│              🌱                     │
│                                     │
│     아직 [X]가 없어요               │ ← "아직" = 기대감
│                                     │
│     [행동 유도 설명]                │ ← 어떻게 하면 되는지
│                                     │
│     [CTA 버튼]                      │ ← 명확한 액션
│                                     │
└─────────────────────────────────────┘
```

### 화면별 빈 상태

| 화면     | 일러스트 | 메시지                 | CTA                   |
| -------- | -------- | ---------------------- | --------------------- |
| Home     | 🌱       | "오늘 할 일이 없어요"  | [로드맵에서 추가하기] |
| Roadmap  | 🗺️       | "아직 목표가 없어요"   | [첫 목표 만들기]      |
| Calendar | 📅       | "배치된 일정이 없어요" | [Task 배치하기]       |
| Review   | 📊       | "기록이 없어요"        | [홈에서 시작하기]     |
| Inbox    | 📭       | "인박스가 비어있어요"  | [메모 추가하기]       |
| Search   | 🔍       | "검색 결과가 없어요"   | [다른 검색어로 시도]  |
| AI Hub   | 🤖       | "대화 기록이 없어요"   | [AI와 대화하기]       |

### 스타일

```
일러스트:
- 크기: 80x80px 또는 이모지 48px
- 색상: Gray 300 또는 Primary 100

메시지:
- 폰트: 16px Medium
- 색상: Gray 600
- 정렬: 중앙

설명:
- 폰트: 14px Regular
- 색상: Gray 500
- 정렬: 중앙

CTA 버튼:
- 스타일: Text 버튼 또는 Outlined
- 색상: Primary

## 공통 UI 컴포넌트

### Task 카드

체크인 카드, 로드맵 Task 등에서 사용

```

┌─────────────────────────────────┐
│ 🏃 매일 30분 걷기 🟢🔥12 30분 │
│ └ 기초 체력(Phase1) · 💪 건강 │
│ 💭 "유산소가 기초 체력의 핵심" │
│ [ ✅ Done ] [ ⏭ Skip ] │
└─────────────────────────────────┘

```

**구성 요소**

| 영역 | 내용 | 필수 |
|------|------|------|
| 좌상단 | 이모지 + Task 이름 | Y |
| 우상단 | Area 컬러 칩 + 스트릭 + 소요시간 | 스트릭 Y, 나머지 N |
| 서브 텍스트 | Phase·Goal·Area 경로 | N |
| Why 행 | 💭 Task.why | N |
| 액션 | Done/Skip 버튼 (Today만) | Today만 |

**상태별 스타일**

| 상태 | 배경색 | 표시 |
|------|--------|------|
| 미완료 | 기본 | - |
| Done | 초록 | ✅ |
| Skip | 회색 | ⏭ |
| Miss | 연한 빨강 | - |

---

### Area 칩/배지

영역 식별을 위한 색상 칩

```

🟢 💪 건강
🔵 📈 커리어
🟣 🧘 멘탈

```

| 속성 | 설명 |
|------|------|
| color | Area별 고유 색상 |
| emoji | Area 이모지 |
| name | Area 이름 (선택적 표시) |

Task가 여러 Area에 연결된 경우:
```

🟢🟣 매일 30분 러닝

```

### 스트릭 배지

연속 완료 카운터

```

🔥 12

```

| 조건 | 표시 |
|------|------|
| 스트릭 0 | 표시 안 함 |
| 스트릭 1+ | 🔥 + 숫자 |
| 5의 배수 | 강조 애니메이션 |

---

### Phase 인디케이터

Goal 내 Phase 진행 상태

```

Phase 1 ●━━ Phase 2 ○━━ Phase 3 ○

```

| 상태 | 표시 |
|------|------|
| 완료 | ● (채워진 원) |
| 현재 | ★ 또는 ● + 강조 |
| 미래 | ○ (빈 원) |

### 진행률 바

```

▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░ 3/5 완료
████████████████░░░░ 78%

```
|------|------|
```
