# AI Hub (AI 코치) Wireframe

## 개요

AI Hub는 **상단 바에서 접근**하는 전체 화면입니다.

- 모바일: 전체 화면 전환 (공통 상단 바 유지)
- 데스크톱: 전체 화면 전환 (공통 상단 바 + 사이드바 유지)

## 섹션별 상세

### 1. 상단 바 (공통 컴포넌트)

- 참고: [top-bar.md](../../components/top-bar.md)
- 높이: 모바일 44px, 데스크톱 56px
- AI Hub 활성 시: 🤖 아이콘 Primary 색상

### 2. 페이지 타이틀

- 요소: "AI 코치" 텍스트
- 크기: 높이 48px, 폰트 24px Bold
- 패딩: 16px

### 3. 환영 메시지

- 요소: 메인 텍스트, 서브 텍스트
- 크기: 패딩 24px
- 스타일: 중앙 정렬, 부드러운 배경색

### 4. 빠른 메뉴 (모바일)

- 요소: 4개 메뉴 카드 (자유 대화, 인사이트, TODO 제안, 타임라인)
- 크기: 카드 높이 64px, 간격 12px
- 스타일: 아이콘 + 타이틀 + 설명, 좌측 정렬

### 5. 빠른 메뉴 (데스크톱)

- 요소: 수평 배치된 4개 버튼
- 크기: 버튼 높이 40px, 간격 12px
- 스타일: 아이콘 + 텍스트, Outlined 버튼

### 6. 최근 대화

- 요소: 대화 히스토리 카드 (아이콘, 제목, 날짜)
- 크기: 카드 높이 48px, 간격 8px
- 동작: 탭 시 해당 대화 이어보기

### 7. 채팅 영역 (데스크톱)

- 요소: 메시지 버블 (AI/사용자), 스크롤 영역
- 크기: max-width 800px, 메시지 버블 max-width 70%
- 스타일:
  - AI 메시지: 좌측 정렬, 밝은 배경
  - 사용자 메시지: 우측 정렬, Primary 배경

### 8. 입력 영역 (데스크톱)

- 요소: 텍스트 입력 필드, 보내기 버튼
- 크기: 높이 52px, 패딩 12px 16px
- 스타일: border-radius 26px, shadow

## 인터랙션

### 탭/클릭

| 요소              | 동작                 |
| ----------------- | -------------------- |
| 상단 바 🤖 아이콘 | AI Hub 화면으로 이동 |
| 빠른 메뉴 카드    | 해당 기능 대화 시작  |
| 최근 대화 카드    | 해당 대화 이어보기   |
| 보내기 버튼       | 메시지 전송          |
| [<] 뒤로가기      | AI Hub 메인으로 복귀 |

### 스와이프

| 방향                    | 동작           |
| ----------------------- | -------------- |
| 최근 대화 좌측          | 삭제 버튼 노출 |
| 채팅 화면 우측 (모바일) | 뒤로가기       |

### 스크롤

| 영역      | 동작                                |
| --------- | ----------------------------------- |
| 메인 화면 | 세로 스크롤                         |
| 채팅 영역 | 세로 스크롤, 새 메시지 시 하단 이동 |
