# Onboarding (온보딩) 페이지

> 내 인생의 방향(Direction)을 함께 찾습니다

---

## 1. 개요

| 항목              | 내용                      |
| ----------------- | ------------------------- |
| **목적**          | Direction(인생 방향) 설정 |
| **진입 조건**     | 첫 회원가입 후            |
| **해결하는 문제** | "내 인생에서 뭘 원하지?"  |

---

## 2. 진입점 & 네비게이션

- **진입**: 회원가입 완료 후 자동
- **이동 가능**: 완료 시 Today (메인 화면)

---

## 3. 3단계 플로우 (MVP)

### Step 1: 가치/방향 칩 선택

```
┌─────────────────────────────────┐
│          Step 1 / 2             │
│   ● ○                           │
│                                 │
│   어떤 삶이 당신을 행복하게 하나요?│
│   (여러 개 선택 가능)            │
│                                 │
│   ┌─────────┐ ┌─────────┐       │
│   │가족과    │ │성장하는 │       │
│   │함께하는  │ │         │       │
│   └─────────┘ └─────────┘       │
│   ┌─────────┐ ┌─────────┐       │
│   │자유로운  │ │안정적인 │       │
│   └─────────┘ └─────────┘       │
│   ┌─────────┐ ┌─────────┐       │
│   │도전하는  │ │창작하는 │       │
│   └─────────┘ └─────────┘       │
│   ┌─────────┐ ┌─────────┐       │
│   │사람들과  │ │+ 직접   │       │
│   │연결된    │ │  입력   │       │
│   └─────────┘ └─────────┘       │
│                                 │
│             [다음 →]             │
└─────────────────────────────────┘
```

**Step 1-2: 가장 중요한 가치**

```
┌─────────────────────────────────┐
│                                 │
│   당신이 가장 중요하게 생각하는  │
│   가치는 무엇인가요? (2~3개 선택)│
│                                 │
│   [건강] [사랑] [성취] [자유]    │
│   [안정] [성장] [기여] [즐거움]  │
│   [+ 직접 입력]                  │
│                                 │
│             [다음 →]             │
└─────────────────────────────────┘
```

### Step 2: Direction 확인 & 수정

```
┌─────────────────────────────────┐
│          Step 2 / 3             │
│   ● ● ○                         │
│                                 │
│   ✨ AI가 추천하는 방향이에요    │
│                                 │
│   ┌─────────────────────────┐   │
│   │                         │   │
│   │  "나는 건강하고 성장하는 │   │
│   │   삶을 통해 가족과 오래  │   │
│   │   행복하게 살고 싶다"    │   │
│   │                         │   │
│   └─────────────────────────┘   │
│                                 │
│   마음에 들면 그대로 시작하고,   │
│   아니면 자유롭게 수정하세요.    │
│   언제든 바꿀 수 있어요.         │
│                                 │
│   [✓ 이대로 시작할게요]          │
│   [✏️ 수정할게요]                │
│   [🔍 아직 모르겠어요]           │
│                                 │
└─────────────────────────────────┘
```

### Step 3: 첫 번째 목표 만들기 (MVP 추가)

```
┌─────────────────────────────────┐
│          Step 3 / 3             │
│   ● ● ●                         │
│                                 │
│   🎯 첫 번째 목표를 만들어볼까요? │
│   작은 것부터 시작해도 괜찮아요  │
│                                 │
│   어떤 영역부터 시작할까요?      │
│                                 │
│   [💪 건강]  [📈 커리어]         │
│   [💰 재정]  [❤️ 관계]           │
│   [🎨 취미]  [+ 직접 입력]       │
│                                 │
│                                 │
│   ────────────────────────────  │
│   예시: "건강" 선택 시           │
│                                 │
│   어떤 목표를 이루고 싶으세요?   │
│   [매일 운동하기]                │
│   [살 빼기]                      │
│   [일찍 자기]                    │
│   [+ 직접 입력]                  │
│                                 │
│         [시작하기]               │
│         [건너뛰기 →]             │
└─────────────────────────────────┘
```

> **MVP 단순화**: 첫 Area 1개와 Goal 1개만 가볍게 만들도록 유도합니다.
> 건너뛰기도 가능하지만, 대부분의 사용자가 첫 목표를 만들고 시작하면 Today 화면이 비어있지 않습니다.

## 4. 기능 목록

| ID      | 기능명              | 설명                                            | 우선순위 |
| ------- | ------------------- | ----------------------------------------------- | -------- |
| ONB-001 | 가치 칩 선택        | 어떤 삶/어떤 가치 복수 선택                     | MVP      |
| ONB-002 | Direction 문장 생성 | 선택한 칩 기반 템플릿 조합 (규칙 기반, AI 아님) | MVP      |
| ONB-003 | Direction 수정      | 직접 문장 편집                                  | MVP      |
| ONB-004 | 탐색 모드           | "아직 모르겠어요" 선택 시 Direction 없이 시작   | MVP      |
| ONB-005 | 첫 목표 가이드      | 첫 Area/Goal 만들기 (건너뛰기 가능)             | MVP      |

```
┌─────────────────────────────────┐

│                                 │
│ 인생의 방향은 살면서             │
│ 찾아가는 거예요.                 │
│                                 │
│ 지금은 방향 없이 시작하고,       │
│ 실천하면서 발견해도 돼요.        │
│                                 │
│ inu가 당신의 패턴을 보면서       │
│ 나중에 제안해드릴게요.           │
│                                 │
│       [탐색하며 시작하기]         │
└─────────────────────────────────┘
```

## 6. 설계 원칙

| 원칙                   | 적용                   |
| ---------------------- | ---------------------- |
| 온보딩은 2단계로 축소  | Direction만 정하고 끝  |
| Area/Goal은 메인에서   | 부담 없이 탐색 후 추가 |
| Direction은 잘 안 바뀜 | 변경은 설정에서만      |
| 탐색 모드 허용         | 방향 없이도 시작 가능  |

---

## 7. 사용자 시나리오

1. 지은이 회원가입 완료
2. 인트로 화면: "내 인생의 방향을 함께 찾아볼게요"
3. Step 1: "가족과 함께하는", "성장하는" 선택
4. Step 1-2: "건강", "성장" 가치 선택
5. Step 2: AI가 추천한 방향 확인 — "언제든 바꿀 수 있어요" 안내
6. "✓ 이대로 시작할게요" 선택
7. Step 3: 첫 번째 목표 만들기 (작은 것부터 시작해도 OK)
8. 메인 화면으로 이동
