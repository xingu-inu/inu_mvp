### 모바일 vs 데스크톱 비교

| 항목        | 모바일                      | 데스크톱                          |
| ----------- | --------------------------- | --------------------------------- |
| 네비게이션  | Step 표시 + 진행 인디케이터 | 동일 (크기 증가)                  |
| 레이아웃    | 전체 화면, 하단 CTA 고정    | 중앙 정렬 (max-width: 640px)      |
| 칩 그리드   | 2~3열 배치                  | 4열 배치                          |
| 여백        | 좌우 24px                   | 좌우 최소 120px                   |
| 버튼 너비   | 전체 너비 - 48px            | max-width: 320px                  |
| 질문 텍스트 | 24px bold                   | 32px bold                         |
| 호버 상태   | 없음                        | 칩/버튼 테두리 색상 변경 + 배경색 |

## 섹션별 상세

### 1. 헤더

- 요소: Step 표시 (예: "Step 1 / 3"), 진행 인디케이터 (원형 도트), 뒤로가기 버튼 (Step 3-2)
- 크기/위치: 높이 44px, Step 텍스트 중앙 정렬 14px, 진행 인디케이터 중앙 Step 아래 8px

### 2. 메인 콘텐츠

- 요소: 질문 텍스트, 부가 설명, 선택 칩/카드
- 크기/위치: 질문 텍스트 24px bold 중앙 정렬, 칩 그리드 좌우 패딩 24px, 칩 간격 12px, 칩 높이 48px

### 3. 하단 CTA

- 요소: Primary 버튼 (다음/시작하기), Secondary 버튼 (건너뛰기, 선택적)
- 크기/위치: 버튼 높이 56px, 좌우 패딩 24px, 하단 패딩 34px (Safe Area)

## 인터랙션

### 탭/클릭

| 요소                  | 동작                                      |
| --------------------- | ----------------------------------------- |
| 칩 탭                 | 선택/해제 토글 (복수 선택 가능)           |
| "+ 직접 입력" 칩      | 텍스트 입력 모달 표시                     |
| "다음" 버튼           | 다음 Step으로 이동 (애니메이션)           |
| "✓ 이대로 시작할게요" | Step 3로 이동                             |
| "✏️ 수정할게요"       | Direction 텍스트 편집 모드                |
| "🔍 아직 모르겠어요"  | 탐색 모드 안내 화면 (Direction 없이 시작) |
| "건너뛰기"            | Today 화면으로 이동                       |
| Area 선택             | Goal 선택 화면으로 전환                   |
| "시작하기"            | Today 화면으로 이동 (첫 Goal 생성됨)      |

### 스와이프

| 방향          | 동작                       |
| ------------- | -------------------------- |
| 좌우 스와이프 | Step 간 이동 (제스처 지원) |

### 스크롤

| 영역           | 동작                         |
| -------------- | ---------------------------- |
| 칩 영역        | 칩이 많을 경우 세로 스크롤   |
| Direction 수정 | 키보드 올라올 때 스크롤 조정 |
