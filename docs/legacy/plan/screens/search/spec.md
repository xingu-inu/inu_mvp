# Search (글로벌 검색) 페이지

> Task/Goal/저널/인박스 통합 검색

---

## 1. 개요

| 항목              | 내용                            |
| ----------------- | ------------------------------- |
| **목적**          | 앱 내 모든 데이터 통합 검색     |
| **진입**          | 상단 바 🔍 아이콘               |
| **해결하는 문제** | "예전에 적어둔 게 어디 있더라?" |

---

## 2. 진입점 & 네비게이션

- **진입**: 상단 바 🔍 검색 아이콘
- **이동 가능**: 검색 결과에서 해당 상세 화면으로

---

## 3. 화면 구성

```
┌─────────────────────────────────┐
│ 🔍 검색...                       │
│                                 │
│ 최근: 포트폴리오, 영어, 운동     │
│                                 │
│ ── 검색 결과: "영어" ──         │
│                                 │
│ 🎯 영어 면접 가능 수준           │
│    📍 커리어 > 영어             │
│                                 │
│ ☑ 영어 뉴스 듣기                │
│    📍 커리어 > 영어 > Phase 1   │
│                                 │
│ 📝 "영어 회화 중단" 저널         │
│    2025.1.31                    │
│                                 │
│ 📥 영어 공부 자료 (인박스)       │
│    2025.2.1                     │
│                                 │
│ 필터: [전체] [목표] [실천] [기록] │
└─────────────────────────────────┘
```

---

## 4. 기능 목록

| ID       | 기능명      | 설명                             | 우선순위 |
| -------- | ----------- | -------------------------------- | -------- |
| SRCH-001 | 통합 검색   | Task/Goal/Phase/Area/저널/인박스 | MVP      |
| SRCH-002 | 로드맵 경로 | 결과에 컨텍스트 표시             | MVP      |
| SRCH-003 | 필터        | 유형별/영역별/상태별             | MVP      |
| SRCH-004 | 최근 검색어 | 최대 10개 저장                   | MVP      |
| SRCH-005 | 결과 이동   | 탭 → 해당 상세 화면              | MVP      |

---

## 5. 검색 대상

| 유형   | 검색 필드 | 결과 표시         |
| ------ | --------- | ----------------- |
| Goal   | 이름, Why | 🎯 + Area 경로    |
| Phase  | 이름, Why | 📍 + Goal > Phase |
| Task   | 이름, Why | ☑ + Phase 경로    |
| 저널   | 내용      | 📝 + 날짜         |
| 인박스 | 내용      | 📥 + 날짜         |
| Area   | 이름, Why | 💪 등 이모지      |

---

## 6. 필터 옵션

| 필터 | 옵션                           |
| ---- | ------------------------------ |
| 유형 | 전체, 목표, 실천, 기록, 인박스 |
| 영역 | Area별 필터                    |
| 상태 | 진행 중, 완료, 보관            |

---

## 7. 사용자 시나리오

### 시나리오: 과거 기록 찾기

1. "예전에 영어 공부 관련해서 뭔가 적었는데..."
2. 상단 바 🔍 탭
3. "영어" 검색
4. Goal, Task, 저널 결과 확인
5. "영어 회화 중단" 저널 탭
6. 저널 상세로 이동 → 과거 기록 확인
