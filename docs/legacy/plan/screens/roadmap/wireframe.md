## 섹션별 상세

### 1. 상단 바 (공통 컴포넌트)

- 참고: [top-bar.md](../../components/top-bar.md)
- 높이: 모바일 44px, 데스크톱 56px

### 2. 헤더

- 요소: "나의 목표" 타이틀, 필터 버튼, 추가 버튼 [+]
- 크기: 높이 48px, 패딩 16px
- 필터: Active / 전체 / Backlog 선택

### 3. 상태 그룹 (Active / Backlog)

- 요소: 상태명 + 개수, 펼침/접힘 화살표
- 크기: 높이 40px, 패딩 16px
- Active: 기본 펼침
- Backlog: 기본 접힘

### 4. Area 카드

- 요소: Area 이모지 + 이름, 펼침/접힘 화살표 (v/>)
- 크기: 헤더 48px, border-radius 16px
- 스타일: 배경 white, shadow 0 2px 8px rgba(0,0,0,0.06)
- 동작: 탭 시 하위 Goal 펼침/접힘

### 5. Goal 행

- 요소: 🎯 아이콘, Goal 이름, Phase 인디케이터, 진행률
- 크기: 높이 56px, 좌측 들여쓰기 16px
- Phase 인디케이터: ●━━○━━○ (완료=●, 미완료=○)
- 동작: 탭 시 Goal 상세 (모바일: 페이지 이동, 데스크톱: 우측 패널)

### 6. Task 행

- 요소: └ 들여쓰기, Task 이름, 스트릭 (있는 경우)
- 크기: 높이 44px, 좌측 들여쓰기 32px
- 동작: 탭 시 Today로 이동하여 해당 Task 표시

### 7. 맵 뷰 진입 버튼

- 요소: 🗺️ 아이콘, "전체 맵으로 보기" 텍스트, 화살표 →
- 크기: 높이 48px, border-radius 12px
- 스타일: 배경 gray 50
- 위치: 리스트 최하단

### 8. 하단 탭 바 (공통 컴포넌트)

- 참고: [navigation.md](../../components/navigation.md)
- 높이: 56px + Safe Area (34px)
- 탭: 오늘, 로드맵\*, 캘린더, 리뷰

## 인터랙션

### 탭/클릭

| 요소                       | 동작                                       |
| -------------------------- | ------------------------------------------ |
| [+] 버튼                   | 목표 추가 바텀시트/모달                    |
| [필터] 버튼                | Active/전체/Backlog 필터                   |
| Area 헤더 (v/>)            | 해당 Area 펼침/접힘                        |
| Goal 행                    | Goal 상세 (모바일: 페이지, 데스크톱: 패널) |
| Task 행                    | Today로 이동하여 해당 Task 표시            |
| 상태 그룹 (Active/Backlog) | 해당 그룹 펼침/접힘                        |
| "전체 맵으로 보기"         | 맵 뷰 화면으로 전환                        |
| 상단 바 아이콘             | 해당 기능으로 이동                         |
| 하단 탭                    | 해당 화면으로 네비게이션                   |

### 스와이프

| 방향      | 동작                |
| --------- | ------------------- |
| Goal 좌로 | Backlog로 이동 옵션 |
| Goal 우로 | Paused로 변경 옵션  |

### 스크롤

| 영역            | 동작            |
| --------------- | --------------- |
| 메인 콘텐츠     | 세로 스크롤     |
| Pull to Refresh | 데이터 새로고침 |

## 맵 뷰 (별도 화면)

"전체 맵으로 보기" 탭 시 전체 화면으로 전환:

```
┌─────────────────────────────────────┐
│  [<]    전체 맵       [줌] [필터]   │ ← 헤더
├─────────────────────────────────────┤
│                                     │
│              ┌─────────────┐        │
│              │  Direction  │        │
│              │  (인생 방향) │        │
│              └──────┬──────┘        │
│     ┌───────────────┼───────────────┤
│     v               v               │
│ ┌────────┐    ┌────────┐           │
│ │ 💪건강 │    │ 📈커리어│           │
│ └───┬────┘    └───┬────┘           │
│     v               v               │
│ ┌────────┐   ┌─────────┐           │
│ │ 10km   │   │  영어   │           │
│ │ 마라톤  │   │  면접   │           │
│ └───┬────┘   └────┬────┘           │
│     ...           ...               │
│                                     │
│                    [핀치: 줌 50-200%]│
│                    [드래그: 팬]      │
├─────────────────────────────────────┤
│  홈    │  *로드맵  │  캘린더  │ 리뷰│
└─────────────────────────────────────┘
```

**맵 뷰 특징:**

- 핀치 줌 (50%~200%)
- 드래그 팬
- 노드 탭 시 해당 항목 상세
- [<] 탭 시 트리 뷰로 복귀
