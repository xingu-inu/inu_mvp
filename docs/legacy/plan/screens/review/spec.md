# Review (리뷰) 페이지

> 회고 & 조정 & 기록 — PDCA의 Check + Act

---

## 1. 개요

| 항목              | 내용                                        |
| ----------------- | ------------------------------------------- |
| **목적**          | 주간/월간 회고, 여정 기록, 성장 궤적 확인   |
| **PDCA 역할**     | **Check + Act** (확인 + 조정)               |
| **해결하는 문제** | "이번 주 얼마나 했지?", "나 성장하고 있나?" |

---

## 2. 진입점 & 네비게이션

- **진입**: 하단 탭 "리뷰"
- **이동 가능**: Roadmap (Goal 조정), Today (패턴 반영), AI 어드바이저

---

## 3. 4개 서브탭

| 서브탭  | 내용                                   | 우선순위 |
| ------- | -------------------------------------- | -------- |
| 📋 주간 | 주간 달성률, AI 인사이트, 10-Step 회고 | MVP      |
| 📅 월간 | 추이 그래프, 영역 균형, 방향 재점검    | Phase 2  |
| 📖 저널 | 여정 타임라인, 자유 기록               | MVP      |
| 📈 성장 | Phase 진행, 달성 목표 리스트           | Phase 2  |

---

## 4. 기능 목록

| ID      | 기능명            | 설명                                                         | 우선순위 |
| ------- | ----------------- | ------------------------------------------------------------ | -------- |
| REV-001 | 주간 달성률       | 이번 주 완료/전체 + 지난주 비교                              | MVP      |
| REV-002 | 스트릭 현황       | 전체 최장, 현재 활성 스트릭                                  | MVP      |
| REV-003 | AI 인사이트       | 규칙 기반 메시지 (MVP) / AI 분석 (Phase 2)                   | MVP\*    |
| REV-004 | 10-Step 주간 회고 | 잘한 점, 어려운 점, 다음 주 계획                             | MVP      |
| REV-005 | 여정 타임라인     | 6종 기록 시간순 표시 (데일리/마일스톤/회고/전환/자유/시스템) | MVP      |
| REV-006 | 자유 기록 작성    | 직접 기록 작성                                               | Phase 2  |
| REV-007 | 월간 추이 그래프  | 주별 달성률 꺾은선                                           | Phase 2  |
| REV-008 | 영역 균형 레이더  | Area별 달성률 차트                                           | Phase 2  |
| REV-009 | Why 온도 체크     | Goal별 동기 유효성 확인                                      | Phase 2  |
| REV-010 | 성장 궤적         | Phase 진행 시각화                                            | Phase 2  |

> **MVP\* 참고**: REV-003 AI 인사이트는 MVP에서 규칙 기반 메시지(스트릭 축하, 달성률 코멘트)만 포함.
> LLM 기반 주간 분석은 Phase 2에서 구현.

## 7. 사용자 시나리오

### 시나리오: 주간 회고

1. 일요일 저녁, 알림: "이번 주를 돌아볼까요?"
2. 리뷰 탭 진입
3. 주간 달성률 78% 확인
4. AI 인사이트 "독서 스트릭 좋아요" 확인
5. "주간 회고 작성하기" 탭
6. 잘한 점: "운동 꾸준히 함"
7. 어려운 점: "영어 공부 시간 부족"
8. 다음 주 다짐: "영어 아침에 하기"
9. 저장 → 저널 타임라인에 회고 카드 생성
