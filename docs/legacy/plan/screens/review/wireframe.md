### 모바일 vs 데스크톱 비교

| 항목        | 모바일                      | 데스크톱                          |
| ----------- | --------------------------- | --------------------------------- |
| 상단 바     | [≡] inu [🔍][📥][🤖] (44px) | [inu] ... [🔍][📥][🤖][👤] (56px) |

## 섹션별 상세

### 1. 상단 바 (공통 컴포넌트)

- 참고: [top-bar.md](../../components/top-bar.md)
- 높이: 모바일 44px, 데스크톱 56px

### 2. 헤더

- 요소: "리뷰" 타이틀
- 크기: 높이 48px, 좌측 정렬

### 3. 서브탭 (MVP: 2탭만)

- 요소: "이번 주", "기록" (2탭)
- 크기: 높이 44px, 균등 분할
- 스타일: 선택됨 = Primary + 밑줄, 미선택 = Gray
- **변경**: 4탭(주간/월간/저널/성장) → 2탭으로 축소 (Phase 2 숨김)

### 4. 달성률 카드

- 요소: 퍼센트 숫자 (크게), 프로그레스 바, 완료 수, 변화율
- 크기: 카드 높이 120px, 숫자 48px 폰트
- 스타일: 배경 white, border-radius 16px
- **핵심**: 숫자를 크게 강조

### 5. 스트릭 섹션

- 요소: "스트릭" 라벨, 스트릭 카드들 (가로 스크롤)
- 카드: Task 이름 + 이모지 + 스트릭 일수
- 크기: 카드 80x80px, 간격 12px
- **구분선 제거**: 여백으로만 구분

### 6. AI 인사이트 카드

- 요소: 💡 아이콘, AI 메시지
- 크기: 높이 56px, padding 12px 16px
- 스타일: 배경 soft yellow/cream, border-radius 12px

### 7. 주간 회고 CTA

- 요소: ✏️ 아이콘, "주간 회고 작성하기" 텍스트
- 크기: 높이 48px, 전체 너비
- 스타일: Primary 버튼 스타일

### 8. 하단 탭 바 (공통 컴포넌트)

- 참고: [navigation.md](../../components/navigation.md)
- 높이: 56px + Safe Area (34px)
- 탭: 오늘, 로드맵, 캘린더, 리뷰\*

## 인터랙션

### 탭/클릭

| 요소                  | 동작                              |
| --------------------- | --------------------------------- |
| 서브탭 (이번 주/기록) | 해당 탭으로 전환                  |
| 스트릭 카드           | Task 상세로 이동                  |
| AI 인사이트 카드      | 관련 Goal/Task로 이동 또는 AI Hub |
| "주간 회고 작성하기"  | 회고 바텀시트/모달 열기           |
| 기록 필터 칩          | 해당 타입만 필터링                |
| 기록 카드             | 상세 보기 (바텀시트/모달)         |
| [+ 기록] FAB          | 자유 기록 작성 바텀시트           |
| 상단 바 아이콘        | 해당 기능으로 이동                |
| 하단 탭               | 해당 화면으로 네비게이션          |

### 스와이프

| 방향                | 동작        |
| ------------------- | ----------- |
| 좌/우 (서브탭)      | 탭 전환     |
| 좌/우 (스트릭 카드) | 가로 스크롤 |
| 좌/우 (필터 칩)     | 가로 스크롤 |

### 스크롤

| 영역             | 동작             |
| ---------------- | ---------------- |
| 메인 콘텐츠      | 세로 스크롤      |
| 스트릭 카드 영역 | 가로 스크롤      |
| 필터 칩 영역     | 가로 스크롤      |
| 기록 타임라인    | 세로 무한 스크롤 |
