## 1. 개요

| 항목              | 내용                                         |
| ----------------- | -------------------------------------------- |
| **목적**          | 빠른 아이디어 캡처, 로드맵 연결 전 임시 저장 |

## 6. 사용자 시나리오

### 시나리오: 빠른 캡처 → 연결

1. 이동 중에 "영어 공부 자료 정리해야지" 생각남
2. 상단 바 📥 탭 → [+] 탭
3. "영어 공부 자료 정리" 입력 → 저장
4. 나중에 인박스 확인
5. "🔗 연결" 탭
6. 커리어 > 영어 면접 가능 수준 선택
7. Task로 연결됨 → 인박스에서 사라짐
