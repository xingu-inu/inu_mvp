### 모바일 vs 데스크톱 비교

| 항목        | 모바일                        | 데스크톱                          |
| ----------- | ----------------------------- | --------------------------------- |
| 네비게이션  | 뒤로가기 + 타이틀 (우측 정렬) | 로고 + 로그인/시작하기 버튼       |
| 레이아웃    | 단일 컬럼, 전체 화면          | 2컬럼 (텍스트 + 이미지)           |
| 캐러셀      | 스와이프 가능한 슬라이드      | 정적인 앱 스크린샷                |
| 폼 위치     | 전체 화면                     | 중앙 정렬 카드 (max-width: 420px) |
| 여백        | 좌우 24px                     | 좌우 최소 120px                   |
| 히어로 영역 | -                             | max-width: 1200px                 |
| 호버 상태   | 없음                          | 버튼/입력 필드 색상 변경          |

## 섹션별 상세

### 1. 헤더

- 요소: 뒤로가기 버튼 (좌측), 타이틀 "회원가입"/"로그인" (우측 정렬)
- 크기/위치: 높이 44px, 좌측 패딩 16px, 타이틀 우측 정렬 16px 패딩

### 2. 랜딩 메인 콘텐츠

- 요소: 로고 (inu), 태그라인, 소개 슬라이드 캐러셀, 페이지 인디케이터
- 크기/위치: 로고 높이 60px, 태그라인 상단에서 180px, 캐러셀 200px 높이, 좌우 패딩 24px

### 3. 입력 폼

- 요소: 입력 필드 (이메일, 비밀번호), 필드 아이콘, 비밀번호 보기 토글
- 크기/위치: 필드 높이 64px (라벨 포함), 입력창 높이 48px, 필드 간격 16px, 좌우 패딩 24px

### 4. CTA 영역

- 요소: Primary 버튼, 보조 텍스트 링크, 소셜 로그인 버튼
- 크기/위치: Primary 56px 높이, 소셜 48px 높이, 버튼 간격 12px, 하단 safe area 34px

## 인터랙션

### 탭/클릭

| 요소                     | 동작                        |
| ------------------------ | --------------------------- |
| "시작하기" 버튼          | 회원가입 화면으로 이동      |
| "로그인" 링크            | 로그인 화면으로 이동        |
| 뒤로가기                 | 이전 화면으로 돌아감        |
| 입력 필드 탭             | 키보드 올라옴 + 포커스 상태 |
| 비밀번호 눈 아이콘       | 비밀번호 표시/숨김 토글     |
| "가입하기" 버튼          | 유효성 검사 후 가입 진행    |
| "로그인" 버튼            | 인증 진행                   |
| "Google로 계속하기"      | Google OAuth 팝업           |
| "Apple로 계속하기"       | Apple OAuth 시트            |
| "비밀번호를 잊으셨나요?" | 비밀번호 재설정 화면        |

### 스와이프

| 방향             | 동작                  |
| ---------------- | --------------------- |
| 랜딩 캐러셀 좌우 | 슬라이드 전환         |
| Auth 화면 좌측   | 뒤로가기 (iOS 제스처) |

### 스크롤

| 영역           | 동작                          |
| -------------- | ----------------------------- |
| Auth 화면      | 키보드 올라올 때 자동 스크롤  |
| 입력 필드 영역 | 키보드에 가려지지 않도록 조정 |
