## 3. 화면 구성

### 3-1. 상단 바

```
┌─────────────────────────────────┐
│ 📥    inu     🤖  👤            │
└─────────────────────────────────┘
  인박스        AI허브 프로필
```

- 🤖 AI 허브: AI 코치 전용 페이지로 이동
- 👤 프로필: 드롭다운 메뉴 표시

### 3-2. 프로필 드롭다운 메뉴

```
┌─────────────────────────────────┐
│ 👤 지은님                        │
│                                 │
│ ⚙️ 설정                          │
│ 📊 나의 통계                     │
│ ─────────────────               │
│ 🚪 로그아웃                      │
└─────────────────────────────────┘
```
