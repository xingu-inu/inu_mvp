# Inu

> 나를 들여다보고, 방향을 그리고,
> 돌아보며 나아가는 나의 여정

내 인생의 방향을 설계하고 나아가는 시스템.

## Name

**inu** — 두 가지 의미를 담고 있다.

- **in-u**: 너 안을 들여다보는 시간. 나를 알아가는 것에서 모든 것이 시작된다.
- **inu**: 일본어로 '개'. 부드럽게, 너의 여정을 함께하는 동반자.

## Philosophy

### Why-First — 나를 들여다보는 것에서 시작한다

모든 목표는 '왜'라는 질문에서 시작한다.
Direction의 why, Goal의 why, Task의 why.
이유를 모르는 목표는 오래 가지 못한다.

### Visual Thinking — 방향을 그린다

생각은 머릿속에만 두면 흐릿해진다.
캔버스에 그리는 순간 명확해진다.
Why Map은 내 인생의 지도다.

### Evolving Design — 돌아보며 나아간다

인생 설계는 한 번에 끝나지 않는다.
방향이 바뀌는 것은 실패가 아니라 성장이다.
기록에 여정을 남기고, 버전을 진화시킨다.

### Together — 함께 나아간다

Inu는 너의 여정을 함께하는 동반자다.
막힐 때 이야기 나누고, 흔들릴 때 같이 정리하고,
다음 방향을 같이 찾아간다.

## Core Experience

2페이지 구조. 설계하는 곳과 기록하는 곳.

### Roadmap — 설계하는 곳

지도처럼 펼쳐진 캔버스에서 내 인생의 방향을 눈으로 보며 설계한다.
큰 방향(Direction) → 삶의 영역(Area) → 목표(Goal) → 묶음(Group) → 할 일(Task),
5단계로 큰 그림부터 구체적인 행동까지 쪼갠다.

#### 캔버스 (Why Map)

| 기능                       | 설명                                                                                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 5가지 블록                 | 방향, 영역, 목표, 묶음, 할 일 — 각각 카드로 캔버스에 표시                                                                                          |
| 3가지 연결선               | 부모-자식 관계, 목표 간 의존관계, 여러 목표에 걸친 할 일                                                                                           |
| 줌에 따른 디테일 변화      | 멀리서 보면 이름만, 가까이 가면 상세 정보까지                                                                                                      |
| 자동 배치                  | 블록들을 계층 구조에 맞게 자동 정렬 (세로/가로)                                                                                                    |
| 마인드맵 레이아웃 (검토중) | Direction을 가운데 두고 Area가 좌/우 양쪽으로 뻗는 마인드맵 스타일. Dual Dagre 방식(LR 2회 실행 + 미러링)으로 구현 가능. Area 수가 많아지면 재검토 |
| 목표 펼치기                | 목표 클릭하면 하위 묶음/할 일을 캔버스에 펼쳐서 보기                                                                                               |
| 집중 모드                  | 선택한 블록의 가지만 밝게, 나머지는 흐리게                                                                                                         |
| 공유 할 일                 | 하나의 할 일이 여러 목표에 걸쳐 있을 때 연결선으로 표시                                                                                            |

#### 오른쪽 패널

| 패널      | 설명                                                  |
| --------- | ----------------------------------------------------- |
| 상세 패널 | 블록 선택하면 오른쪽에 자동으로 열림, `]`로 열고 닫기 |
| 목록 탐색 | 영역 → 목표 → 묶음 → 할 일을 접었다 펼치며 탐색       |
| 보기/편집 | 선택한 항목의 상세 정보 보기 및 수정                  |

#### 바로 편집 (인라인)

| 대상             | 할 수 있는 것                                    |
| ---------------- | ------------------------------------------------ |
| 방향 (Direction) | 수정 (한 줄 선언, 이유)                          |
| 영역 (Area)      | 만들기, 수정 (이름, 이유, 이모지, 색상, 유형)    |
| 목표 (Goal)      | 만들기, 수정, 완료 처리 (이름, 이유, 기간, 상태) |
| 묶음 (Group)     | 만들기, 수정 (이름)                              |
| 할 일 (Task)     | 만들기, 수정, 빠른 입력 (이름, 이유)             |
| 공통             | 상태 변경, 삭제 확인                             |

#### AI 채팅 (오른쪽 패널)

로드맵의 모든 AI 기능은 채팅 대화를 통해 실행된다.
오른쪽 패널에서 AI와 대화하면서 자연스럽게 로드맵을 만들고 다듬는다.

| 할 수 있는 것 | 예시 대화                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------ |
| 쏟아내기      | "운동하고 싶어" → AI가 즉시 영역/목표/할 일 예시 구조를 카드로 제안 → 칩으로 수정 → 확인 후 생성 |
| 건강 진단     | "내 로드맵 좀 봐줘" → 전체 또는 특정 영역/목표 분석 → 제안                                       |
| 목표 쪼개기   | "이 목표를 구체적으로 나눠줘" → 묶음/할 일로 분해                                                |
| Why 생성      | "왜 이걸 해야 할까?" → '왜' 텍스트 제안                                                          |
| 목표 제안     | "건강 영역에 뭘 추가하면 좋을까?" → 목표 추천                                                    |
| 할 일 추천    | "이 목표에 어떤 할 일이 필요할까?" → 할 일 제안                                                  |
| 고민 상담     | "요즘 방향을 모르겠어" → 대화하며 정리                                                           |

### 기록 — 나를 기록하는 곳

두 영역으로 구성된다.

#### 나에 대한 데이터 (자유 프로필)

나에 대한 정보를 자유롭게 기록하는 공간. 사용자가 라벨과 값을 직접 정의한다.
예: MBTI, 강점, 요즘 관심사, 에너지 충전법, 피하고 싶은 패턴 등.
항목마다 설정한 날짜가 남는다.

#### 나의 흐름 (타임라인) — Phase 2 예정

| 이벤트 유형        | 설명                                 |
| ------------------ | ------------------------------------ |
| 목표 상태 변경     | Active → Paused, Completed 등 + 이유 |
| 방향 변경          | Direction 수정/전환 기록             |
| 프로필 항목 변경   | 자유 프로필 항목 추가/수정/삭제 이력 |
| AI 대화 하이라이트 | 주요 대화 요약                       |

## Data Model

```
Direction (인생의 큰 방향)
  └─ Area (삶의 영역: 건강, 커리어, 관계 등)
      └─ Goal (구체적 목표)
          └─ Group (선택적 묶음)
              └─ Task (할 일)
```

5단계 계층. 모든 항목에 '왜(why)' 필드가 있다.
목표는 6가지 상태: 진행중 / 대기 / 완료 / 유지 / 멈춤 / 보관

## AI — 대화로 하는 모든 것

모든 AI 기능은 채팅 대화를 통해 실행된다.
AI는 현재 로드맵 상태를 이해하고 있어서, 대화하면서 바로 로드맵을 만들고 수정할 수 있다.
사용자가 아이디어를 말하면 즉시 예시 구조를 카드로 제안하고, 대화하면서 함께 다듬는다.
모든 AI 응답 끝에 응답 칩(2-4개)을 제공해 클릭만으로 쉽게 대화를 이어간다.

### 자유 프로필 — 나를 기억하는 방식

이누는 단순히 목표를 쪼개는 도구가 아니라,
나의 방향과 리듬을 함께 이해하는 동행자여야 한다.

사용자가 **라벨과 값을 자유롭게 정의**하는 `profile_traits` 테이블에 저장한다.
시스템이 카테고리를 강제하지 않고, 넣고 싶은 만큼만 넣는다.

이 프로필은 상담, 목표 제안, 방향 점검에서
"무조건 더 하기"보다 "나답게 나아가기"를 돕는 기준으로 사용된다.
AI 대화 중 사용자에 대해 새로운 것을 알게 되면, `suggest_profile_traits` 도구로 프로필 항목을 제안한다.
사용자는 채팅 내 카드 UI에서 체크박스로 선택/해제 후 일괄 저장할 수 있다.
"나에 대해 정리해줘" 퀵액션으로 대화 내용 기반 프로필 일괄 정리도 가능하다.

| 할 수 있는 것 | 설명                                                                   |
| ------------- | ---------------------------------------------------------------------- |
| 쏟아내기      | 아이디어를 말하면 즉시 영역/목표/할 일 구조를 카드로 제안, 칩으로 수정 |
| 목표 제안     | 영역에 맞는 목표를 추천                                                |
| 목표 쪼개기   | 목표를 묶음/할 일로 분해                                               |
| Why 생성      | '왜 이걸 하는지' 텍스트를 제안                                         |
| 할 일 추천    | 목표에 맞는 할 일을 추천                                               |
| 건강 진단     | 로드맵의 균형과 건강도를 진단하고 제안                                 |
| 구조 분석     | 목표의 구성이 잘 되어있는지 분석                                       |
| 고민 상담     | 방향을 모르겠을 때 대화하면서 같이 정리                                |

## Tech Stack

- Next.js 16.1 (App Router, RSC), React 19.2, TypeScript 5.9
- Tailwind CSS 4.0, Radix UI, Framer Motion, Lucide React
- TanStack Query v5 (server state), Zustand (client state), nuqs (URL state)
- react-hook-form + Zod
- Supabase (PostgreSQL, Auth, Edge Functions)
- ReactFlow (Why Map 캔버스)
- fractional-indexing (정렬)
- Vitest, Playwright, @testing-library/react

## Target Users

- 나 자신 — 우선 내가 쓰는 도구
- 방향을 잃은 사람들 — 인생이 복잡해져서 정리가 필요한 사람
- 목표 지향적인 사람들 — 목표가 있지만 체계적으로 관리하고 싶은 사람
